# LeetCode 713：乘積小於 K 的子陣列

這是一個使用 C# 與 .NET 10 撰寫的主控台教學專案，示範如何運用滑動視窗，在線性時間內計算乘積嚴格小於 `k` 的連續非空子陣列數量。

> 題目連結：[713. Subarray Product Less Than K](https://leetcode.com/problems/subarray-product-less-than-k/description/)

## 題目說明

給定一個正整數陣列 `nums` 與整數 `k`，請回傳所有元素乘積嚴格小於 `k` 的連續非空子陣列數量。

以 `nums = [10, 5, 2, 6]`、`k = 100` 為例，符合條件的子陣列共有 8 個：

```text
[10]、[5]、[2]、[6]、[10, 5]、[5, 2]、[2, 6]、[5, 2, 6]
```

`[10, 5, 2]` 的乘積剛好等於 100，因為題目要求「嚴格小於」`k`，所以不能計入。

## 限制條件與輸入前提

- `1 <= nums.Length <= 3 * 10^4`
- `1 <= nums[i] <= 1000`
- `0 <= k <= 10^6`
- 子陣列必須連續且非空。
- 公開方法依照上述題目限制設計，不額外處理 `null`、空陣列、零或負數元素。

所有元素都是正整數，是滑動視窗成立的關鍵：右端加入元素時乘積只會增加或維持不變；左端移除元素時乘積只會減少或維持不變。因此左右指標都只需要向右移動，不必回頭重新枚舉。

## 解題概念與出發點

最直觀的方法是列舉每一個起點與終點，再計算區間乘積。即使沿用前一個乘積避免重算，仍需檢查 `O(n^2)` 個子陣列，無法充分利用正整數乘積的單調性。

本專案保留一種解法：

| 方法 | 核心概念 | 時間複雜度 | 額外空間 |
| --- | --- | --- | --- |
| `NumSubarrayProductLessThanK` | 維護乘積小於 `k` 的滑動視窗 | `O(n)` | `O(1)` |

滑動視窗以 `[start, end]` 表示目前考慮的連續區間：

1. 將 `nums[end]` 乘進 `product`，擴張視窗右端。
2. 若 `product >= k`，持續除以 `nums[start]` 並將 `start` 右移，直到視窗乘積重新嚴格小於 `k`，或視窗縮成空區間。
3. 固定目前的 `end` 後，合法起點是 `start`、`start + 1`、……、`end`，因此會新增 `end - start + 1` 個合法子陣列。
4. 將 `end` 右移，繼續處理下一個元素。

## 解法設計詳解

### 視窗狀態

- `start`：目前最左側的合法起點。
- `end`：本輪新加入的元素索引。
- `product`：目前 `[start, end]` 視窗內所有元素的乘積。
- `count`：截至目前為止找到的合法連續子陣列總數。

### 為什麼可以一次加入 `end - start + 1`

縮小視窗結束後，`[start, end]` 的乘積已經嚴格小於 `k`。因為陣列元素都是正整數，從左側再移除任意數量的元素不會讓乘積增加，所以：

```text
[start, end]
[start + 1, end]
...
[end, end]
```

全部都是合法子陣列。這些子陣列都以本輪的 `end` 結尾，而且先前輪次尚未計算過，因此可以安全地一次加入 `end - start + 1`。

### 為什麼不會漏掉答案

當 `product >= k` 時，目前 `start` 對應的視窗不合法。由於元素皆為正整數，如果不移除左端元素，繼續向右加入元素也不可能讓乘積變小。因此必須將 `start` 右移。縮窗停止時，`start` 是本輪能形成合法視窗的最左位置，所以所有以 `end` 結尾的合法子陣列恰好就是上述 `end - start + 1` 個。

### 邊界情況

- `k = 0` 或 `k = 1`：正整數子陣列的乘積至少為 1，因此答案必為 0。程式會把每一輪視窗縮成空區間，新增數量為 0。
- 單一元素：元素本身小於 `k` 時得到 1，否則得到 0。
- 重複的 1：乘積不會增加，但每個不同的起訖位置仍是不同子陣列。例如三個 1 共有 `3 + 2 + 1 = 6` 個子陣列。
- 乘積剛好等於 `k`：因條件是嚴格小於，必須縮小視窗，不能計入。

### 複雜度分析

`end` 從左到右走訪一次，每個元素也最多被 `start` 移出視窗一次，因此總操作次數與陣列長度成正比：

- 時間複雜度：`O(n)`
- 額外空間複雜度：`O(1)`

## 範例演示流程

以 `nums = [10, 5, 2, 6]`、`k = 100` 為例：

| `end` | 加入元素 | 加入後乘積 | 縮窗動作 | 合法視窗 | 本輪新增 | 累計 |
| ---: | ---: | ---: | --- | --- | ---: | ---: |
| 0 | 10 | 10 | 不需縮窗 | `[10]` | 1 | 1 |
| 1 | 5 | 50 | 不需縮窗 | `[10, 5]` | 2 | 3 |
| 2 | 2 | 100 | 移除 10，乘積變為 10 | `[5, 2]` | 2 | 5 |
| 3 | 6 | 60 | 不需縮窗 | `[5, 2, 6]` | 3 | 8 |

各輪新增的子陣列如下：

1. `end = 0`：`[10]`
2. `end = 1`：`[5]`、`[10, 5]`
3. `end = 2`：`[2]`、`[5, 2]`
4. `end = 3`：`[6]`、`[2, 6]`、`[5, 2, 6]`

最後得到 8 個合法子陣列。
