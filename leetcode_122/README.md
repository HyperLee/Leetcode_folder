## 題目說明

給定整數陣列 `prices`，其中 `prices[i]` 代表第 `i` 天的股價。每天可以買入或賣出股票，交易次數不受限制，但任何時候最多只能持有一股；再次買入前必須先賣出目前持股。

目標是回傳所有合法交易能取得的最大總利潤。如果沒有任何有利可圖的交易，答案為 `0`。

官方範例：

```text
輸入：prices = [7, 1, 5, 3, 6, 4]
輸出：7
```

可以在價格 `1` 時買入、`5` 時賣出，取得 `4`；再於價格 `3` 時買入、`6` 時賣出，取得 `3`，總利潤為 `7`。

- [LeetCode 英文題目](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/description/)
- [LeetCode 中文題目](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/description/)

## 限制條件

- `1 <= prices.Length <= 30,000`
- `0 <= prices[i] <= 10,000`
- 可以完成任意次交易，但同一時間最多持有一股。
- 可以在同一天賣出後再次買入，只要持股數不超過一股。

依照上述限制，兩個解法都直接處理非空陣列，不另外定義 `null` 或空陣列的行為。

## 解題概念與出發點

題目的關鍵是「交易次數不受限制」。只要明天的價格比今天高，就可以把這段漲幅視為一天的利潤並收集起來。

例如價格連續從 `1` 上漲到 `3`，再上漲到 `6`：

```text
一次交易：6 - 1 = 5
拆成兩段：(3 - 1) + (6 - 3) = 2 + 3 = 5
```

因此，一段連續上漲可以拆成所有相鄰正價差，而且總利潤不變。這形成解法一的貪心策略。另一方面，也可以把每天收盤後的持股狀態明確建模，形成解法二的動態規劃策略。

## 解法一：相鄰正價差貪心法

### 設計說明

`MaxProfit` 從第二天開始比較 `prices[i]` 與 `prices[i - 1]`：

1. 若今天價格高於昨天，加入 `prices[i] - prices[i - 1]`。
2. 若今天價格沒有上漲，加入 `0`，等同不進行這一段交易。
3. 掃描完成後，所有正價差總和就是最大利潤。

這個策略不需要真的記錄買入與賣出日期。每次只收集局部確定能得到的上漲幅度，就不會錯過任何可獲利區間。

### 正確性直覺

對任一連續上漲區間 `p0 < p1 < ... < pk`：

```text
(p1 - p0) + (p2 - p1) + ... + (pk - p(k-1)) = pk - p0
```

所以收集每日正價差，與在谷底買入、峰頂賣出的利潤完全相同。下降或持平區間沒有正利潤，忽略它們不會降低答案。

### 範例演示

`prices = [7, 1, 5, 3, 6, 4]`

| 比較日期 | 計算 | 本次加入 | 累積利潤 |
| --- | ---: | ---: | ---: |
| 第 1 → 2 天 | `1 - 7 = -6` | `0` | `0` |
| 第 2 → 3 天 | `5 - 1 = 4` | `4` | `4` |
| 第 3 → 4 天 | `3 - 5 = -2` | `0` | `4` |
| 第 4 → 5 天 | `6 - 3 = 3` | `3` | `7` |
| 第 5 → 6 天 | `4 - 6 = -2` | `0` | `7` |

最後回傳 `7`。

### 複雜度

- 時間複雜度：`O(n)`，只掃描股價陣列一次。
- 額外空間複雜度：`O(1)`，只保存累積利潤。

## 解法二：雙狀態動態規劃

### 設計說明

`MaxProfit2` 將每天收盤後的最佳結果分成兩個狀態：

- `cash`：當天結束時沒有持股的最大利潤。
- `hold`：當天結束時持有一股的最大利潤。

第一天的初始狀態：

```text
cash = 0
hold = -prices[0]
```

之後每天使用前一天的狀態快照進行轉移：

```text
newCash = max(previousCash, previousHold + currentPrice)
newHold = max(previousHold, previousCash - currentPrice)
```

`newCash` 在「繼續不持股」與「賣出持股」之間取較佳者；`newHold` 在「繼續持股」與「今天買入」之間取較佳者。兩個狀態必須共同使用更新前的值，才能維持「從前一天轉移到今天」的明確定義。

最後一天必須以未持股狀態結束，因為尚未賣出的股票不能算成已實現利潤，所以回傳 `cash`。

### 範例演示

`prices = [7, 1, 5, 3, 6, 4]`

| 天數 | 當日價格 | `cash` | `hold` | 狀態重點 |
| --- | ---: | ---: | ---: | --- |
| 第 1 天 | `7` | `0` | `-7` | 不買，或以 7 買入 |
| 第 2 天 | `1` | `0` | `-1` | 改在更低的價格買入 |
| 第 3 天 | `5` | `4` | `-1` | 賣出後實現利潤 4 |
| 第 4 天 | `3` | `4` | `1` | 使用既有利潤再次買入 |
| 第 5 天 | `6` | `7` | `1` | 再次賣出，總利潤成為 7 |
| 第 6 天 | `4` | `7` | `3` | 保留未持股狀態的利潤 7 |

最後回傳 `cash = 7`。

### 複雜度

- 時間複雜度：`O(n)`，每一天只進行固定次數的狀態轉移。
- 額外空間複雜度：`O(1)`，使用變數壓縮原本的 DP 表格。

## 兩種解法比較

| 比較項目 | `MaxProfit` 貪心法 | `MaxProfit2` 動態規劃 |
| --- | --- | --- |
| 核心觀點 | 收集所有相鄰正價差 | 維護每日持股／未持股最佳值 |
| 時間複雜度 | `O(n)` | `O(n)` |
| 額外空間 | `O(1)` | `O(1)` |
| 優點 | 程式短、直接呈現本題性質 | 狀態與交易決策清楚 |
| 延伸性 | 適合目前無限制交易條件 | 容易延伸到手續費、冷卻期或交易次數限制 |

兩者在本題都能得到相同答案。貪心法是最精簡的解法；動態規劃法則提供較通用的股票問題建模方式。
