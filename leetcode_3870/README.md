## 題目說明

給定一個整數 `n`，請計算從 `1` 到 `n`（包含兩端）的所有整數，
以標準數字格式書寫時總共使用了多少個逗號。

標準數字格式的規則是：

- 從數字右側開始，每三位數字插入一個逗號。
- 少於四位數的數字不包含逗號。

### 官方範例 1

```text
n = 1002
輸出 = 3
```

`1,000`、`1,001` 與 `1,002` 各包含一個逗號，因此總數為 `3`。

### 官方範例 2

```text
n = 998
輸出 = 0
```

`1` 到 `998` 都少於四位數，因此不需要逗號。

## 限制條件

依照 [LeetCode 官方題目頁](https://leetcode.com/problems/count-commas-in-range/)：

- `1 <= n <= 10^5`

這個限制是解法推導的關鍵。最大的 `n` 是 `100000`，仍然只有六位數，
所以從 `1000` 到 `n` 的每個數字都恰好包含一個逗號，不會出現需要兩個逗號的七位數字。

本專案遵循 LeetCode 的輸入契約，不另外處理 `n <= 0` 或超出限制的輸入。

## 解題概念與出發點

先觀察逗號第一次出現的位置：

```text
1       到 999       ：0 個逗號
1000    到 100000    ：每個數字恰好 1 個逗號
```

因此，題目可以轉化為「計算區間 `[1000, n]` 有多少個整數」：

```text
如果 n < 1000：答案為 0
如果 n >= 1000：答案為 n - 1000 + 1 = n - 999
```

這個觀察產生兩種不同取向的解法：

1. 保留題目定義，逐一檢查 `1` 到 `n`，適合展示最直接的遍歷思路。
2. 直接使用區間數量公式，跳過不必要的逐一檢查，得到常數時間解法。

## 解法一：遍歷計數

對應程式方法：`CountCommas(int n)`。

### 設計說明

此方法按照題目敘述，從 `1` 遍歷到 `n`。當目前數字至少為 `1000` 時，
就將答案增加一次：

```text
count = 0

for value = 1 to n:
    if value >= 1000:
        count += 1

return count
```

這裡不是把每個整數轉成字串再計算逗號，而是利用題目限制進行判斷。
因為 `n <= 10^5`，所有被計數的數字都只有四到六位數，每個數字恰好貢獻一個逗號。

### 範例演示：`n = 1002`

1. `1` 到 `999` 都小於 `1000`，不增加計數，`count = 0`。
2. 遇到 `1000`，它的格式是 `1,000`，`count = 1`。
3. 遇到 `1001`，它的格式是 `1,001`，`count = 2`。
4. 遇到 `1002`，它的格式是 `1,002`，`count = 3`。
5. 遍歷完成，回傳 `3`。

### 邊界演示：`n = 1000`

迴圈必須包含上限 `n`。當 `value = 1000` 時就應該計數一次，因此答案是 `1`。
這也能捕捉常見的 `value < n` 或從 `0` 開始造成的 off-by-one 錯誤。

### 正確性說明

- `1` 到 `999` 的數字少於四位數，依題意不含逗號。
- 在題目限制內，`1000` 到 `n` 的數字都是四到六位數，各含一個逗號。
- 迴圈完整走訪包含端點的 `[1, n]`，只對第二個區間增加計數。

因此，最後的 `count` 正好等於所有整數使用的逗號總數。

### 複雜度

- 時間複雜度：`O(n)`，逐一檢查 `1` 到 `n`。
- 額外空間複雜度：`O(1)`，只使用計數器與迴圈變數。

## 解法二：直接計算

對應程式方法：`CountCommas2(int n)`。

### 設計說明

第一個含逗號的數字是 `1000`。如果 `n >= 1000`，包含逗號的數字形成一個包含端點的區間：

```text
[1000, n]
```

這個區間的元素數量為：

```text
n - 1000 + 1 = n - 999
```

當 `n < 1000` 時，區間不存在，答案應為 `0`。程式以 `Math.Max` 同時處理兩種情況：

```csharp
return Math.Max(n - 999, 0);
```

### 範例演示：`n = 1002`

1. 計算包含逗號的區間 `[1000, 1002]`。
2. 區間長度為 `1002 - 1000 + 1 = 3`。
3. 回傳 `Math.Max(1002 - 999, 0) = 3`。

### 範例演示：`n = 998`

1. `998 - 999 = -1`。
2. 逗號數量不能是負數。
3. `Math.Max(-1, 0)` 回傳 `0`。

### 正確性說明

在合法輸入範圍內，只有 `[1000, n]` 的整數需要計數，且每個整數恰好貢獻一個逗號。
因此答案就是該區間的元素數量；`Math.Max(n - 999, 0)` 正好分別處理區間存在與不存在的情況。

### 複雜度

- 時間複雜度：`O(1)`。
- 額外空間複雜度：`O(1)`。
