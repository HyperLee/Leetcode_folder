# LeetCode 3863：將字串排序所需的最少操作次數

![.NET 10](https://img.shields.io/badge/.NET-10-512BD4?logo=dotnet&logoColor=white)

以 C# 實作 LeetCode 3863，並在主程式中執行固定範例，核對分類討論解法的輸出。

- 題目：[3863. Minimum Operations to Sort a String](https://leetcode.com/problems/minimum-operations-to-sort-a-string/description/)
- 專案：`leetcode_3863/leetcode_3863.csproj`
- 執行範例：`leetcode_3863/Program.cs` 中的 `Main`

## 題目說明

給定只包含小寫英文字母的字串 `s`。一次操作可以選取 `s` 中任何一個「不是整個字串」的連續子字串，並將該子字串依字母順序非遞減排序。請回傳讓整個字串有序所需的最少操作次數；若無法完成則回傳 `-1`。

### 限制條件

- `1 <= s.length <= 10^5`
- `s` 只包含小寫英文字母。

主程式提供涵蓋所有可能回傳值的範例：

| 輸入 | 預期結果 | 說明 |
| --- | ---: | --- |
| `abc` | 0 | 已經排序完成 |
| `dog` | 1 | 一次操作即可完成 |
| `card` | 2 | 需要兩次操作 |
| `dcba` | 3 | 需要三次操作 |
| `gf` | -1 | 長度為 2 且未排序，無法改變順序 |

## 解題概念與出發點

直接模擬每種子字串排序並不必要。題目限制每次不能排序整個字串，因此操作能否把全域最小字元移到開頭、或把全域最大字元移到結尾，是判斷操作次數的關鍵。

解法在一次掃描中收集三項資訊：

1. 字串中的最小字元 `mn`。
2. 字串中的最大字元 `mx`。
3. 是否存在相鄰逆序；若沒有，字串已經非遞減排序。

掃描完成後，依序檢查字串狀態與極值位置。全程只保留固定數量的變數，不建立排序後的副本。

## 解法：單次掃描與分類討論

### 掃描階段

令 `n = s.Length`，初始時以 `'z'` 作為最小值、`'a'` 作為最大值，並假設字串已排序。逐一讀取每個字元：

- 更新 `mn` 與 `mx`。
- 若某一對相鄰字元滿足 `s[i - 1] > s[i]`，就標記字串未排序。

這個判斷足以確認整體順序：只要每一對相鄰字元都符合非遞減順序，整個字串就已排序。

### 分類階段

依以下順序回傳結果：

| 判斷順序 | 條件 | 最少操作 | 理由 |
| --- | --- | ---: | --- |
| 1 | 字串已排序 | 0 | 不需要執行操作。 |
| 2 | 字串未排序且長度為 2 | -1 | 合法子字串只能是單一字元，排序不會交換兩個字元。 |
| 3 | `s[0] == mn` 或 `s[n - 1] == mx` | 1 | 最小值已在左端，或最大值已在右端；排序其餘部分即可完成。 |
| 4 | 內部位置出現 `mn` 或 `mx` | 2 | 先將內部極值移到正確端點，再排序剩餘區段。 |
| 5 | 以上條件皆不成立 | 3 | 最小值只在最右端，最大值只在最左端，需要分別整理兩端及中間順序。 |

`s[0] == mn` 與 `s[n - 1] == mx` 的判斷必須在內部極值判斷之前。符合其中一項時，答案已經是 1；後續的兩次操作情況只處理不能一次完成的字串。

### 各情況的操作演示

#### 0 次：`abc`

`abc` 的相鄰字元都符合非遞減順序，因此直接回傳 0，不執行任何操作。

#### 1 次：`dog`

最小字元 `d` 已在開頭。排序不包含第一個字元的後綴 `og`：

1. `dog` → `dgo`

結果 `dgo` 已排序，因此回傳 1。

#### 2 次：`card`

`card` 的最小字元 `a` 與最大字元 `r` 都在內部，不能一次完成。依序整理前綴與後綴：

1. 排序前綴 `car`：`card` → `acrd`。
2. 排序後綴 `rd`：`acrd` → `acdr`。

結果已排序，因此回傳 2。

#### 3 次：`dcba`

最大字元 `d` 在最左端，最小字元 `a` 在最右端，兩者都不在排序後應有的端點。每次操作不能選取整個字串，以下三次操作逐步整理兩端：

1. 排序前綴 `dcb`：`dcba` → `bcda`。
2. 排序索引 1 到 3 的子字串 `cda`：`bcda` → `bacd`。
3. 排序前綴 `bac`：`bacd` → `abcd`。

每次選取的子字串都不是整個字串；三次後完成排序。

#### 無法排序：`gf`

`gf` 長度為 2 且順序錯誤。任何合法子字串都只有一個字元，排序後字串仍是 `gf`，所以回傳 -1。

### 正確性直覺

- 若字串已排序，0 次是最少可能操作數。
- 若長度為 2 且未排序，任何合法操作都不能改變字元順序，因此答案是 -1。
- 若最小值在左端或最大值在右端，排序不包含該端點的剩餘子字串即可完成，答案是 1。
- 若最小值或最大值在內部，將包含該極值的前綴或後綴排序，可先把極值移到正確端點；再排序另一側剩餘區段即可完成，答案是 2。
- 最後一類字串的最大值在左端、最小值在右端，且沒有內部極值。一次操作不能同時選取兩端；兩次操作也無法同時將兩個端點極值放到位並整理中間，因此至少需要 3 次。先排序前綴、再排序後綴、最後再次排序前綴，可在 3 次內完成。

### 複雜度

- 時間複雜度：`O(n)`，掃描字串一次。
- 額外空間複雜度：`O(1)`，只使用固定數量的區域變數。
