# 3411. 最長乘積等價子陣列

英文題名：Maximum Subarray With Equal Products

[LeetCode 官方題目](https://leetcode.com/problems/maximum-subarray-with-equal-products/description/)

## 題目描述

給定一個由**正整數**組成的陣列 `nums`。

對於陣列 `arr`，若它的所有元素相乘，等於其最小公倍數乘上最大公因數，就稱它為**乘積等價陣列**。也就是滿足：

```text
prod(arr) == lcm(arr) * gcd(arr)
```

- `prod(arr)` 是 `arr` 所有元素的乘積。
- `gcd(arr)` 是 `arr` 所有元素的最大公因數。
- `lcm(arr)` 是 `arr` 所有元素的最小公倍數。

子陣列由 `nums` 中一段索引連續的元素組成。請回傳 `nums` 中**最長的乘積等價子陣列的長度**。

## 範例

### 範例一

- 輸入：`nums = [1, 2, 1, 2, 1, 1, 1]`
- 輸出：`5`
- 說明：取最後五個元素 `[1, 2, 1, 1, 1]`。乘積為 `2`，最小公倍數為 `2`，最大公因數為 `1`，滿足 `2 = 2 × 1`。

### 範例二

- 輸入：`nums = [2, 3, 4, 5, 6]`
- 輸出：`3`
- 說明：取中間三個元素 `[3, 4, 5]`。乘積為 `60`，最小公倍數為 `60`，最大公因數為 `1`，滿足 `60 = 60 × 1`。

### 範例三

- 輸入：`nums = [1, 2, 3, 1, 4, 5, 1]`
- 輸出：`5`
- 說明：取最後五個元素 `[3, 1, 4, 5, 1]`。乘積為 `60`，最小公倍數為 `60`，最大公因數為 `1`，滿足 `60 = 60 × 1`。

## 輸入限制

- `2 <= nums.length <= 100`（陣列包含 2 到 100 個元素）。
- `1 <= nums[i] <= 10`（每個元素都是 1 到 10 的整數）。
