# 3411. 最長乘積等價子陣列

英文題名：Maximum Subarray With Equal Products

[LeetCode 官方題目](https://leetcode.com/problems/maximum-subarray-with-equal-products/description/)

## 題目描述

給定一個由**正整數**組成的陣列 `nums`。

對於陣列 `arr`，若它的所有元素相乘，等於其最小公倍數乘上最大公因數，就稱它為**乘積等價陣列**。也就是滿足：

```text
prod(arr) == lcm(arr) * gcd(arr)
```

- `prod(arr)` 是 `arr` 所有元素的乘積。
- `gcd(arr)` 是 `arr` 所有元素的最大公因數。
- `lcm(arr)` 是 `arr` 所有元素的最小公倍數。

子陣列由 `nums` 中一段索引連續的元素組成。請回傳 `nums` 中**最長的乘積等價子陣列的長度**。

## 解題前先認識最大公因數與最小公倍數

### 元素的最大公因數（GCD）

如果一個正整數能整除陣列中的每個元素，它就是這些元素的**公因數**。最大的公因數就是**最大公因數**，記作 `gcd(arr)`。

以 `arr = [4, 6, 8]` 為例，分別列出每個元素的正因數。

- `4` 的正因數有 `1、2、4`。
- `6` 的正因數有 `1、2、3、6`。
- `8` 的正因數有 `1、2、4、8`。

三份清單都有 `1` 和 `2`，其中最大的是 `2`，所以 `gcd([4, 6, 8]) = 2`。

#### 用輾轉相除法計算 GCD

對兩個正整數 `a` 和 `b`，先算 `a % b`，也就是 `a` 除以 `b` 的餘數。接著把 `(a, b)` 換成 `(b, a % b)`，因為這兩組數的公因數相同。重複這個步驟，直到第二個數變成 `0`，此時第一個數就是 GCD。

如果有三個以上的數，先算前兩個數的 GCD，再把結果與下一個數求 GCD。沿用 `[4, 6, 8]`，依照陣列順序計算。

1. **先算 `gcd(4, 6)`。** `4 % 6 = 4`，所以變成 `(6, 4)`。接著 `6 % 4 = 2`，變成 `(4, 2)`。最後 `4 % 2 = 0`，得到 `(2, 0)`，因此 GCD 是 `2`。
2. **把結果 `2` 和下一個數 `8` 合併。** `2 % 8 = 2`，所以變成 `(8, 2)`。接著 `8 % 2 = 0`，得到 `(2, 0)`，因此 GCD 仍是 `2`。

因此 `gcd([4, 6, 8]) = gcd(gcd(4, 6), 8) = 2`，與列出因數得到的結果相同。

### 元素的最小公倍數（LCM）

如果一個正整數能被陣列中的每個元素整除，它就是這些元素的**公倍數**。**最小公倍數**是**能被陣列中每個元素整除的最小正整數**，記作 `lcm(arr)`。

同樣以 `arr = [4, 6, 8]` 為例，公倍數一定是 `8` 的倍數，所以可以從小到大檢查 `8` 的正倍數。

- `8` 和 `16` 都能被 `4` 整除，但都不能被 `6` 整除。
- `24` 能被 `4`、`6` 和 `8` 整除，因為 `24 ÷ 4 = 6`、`24 ÷ 6 = 4`、`24 ÷ 8 = 3`。

`24` 是第一個同時能被 `4`、`6` 和 `8` 整除的正整數，所以 `lcm([4, 6, 8]) = 24`。

#### 用最大公因數計算 LCM

對兩個正整數 `a` 和 `b`，可以先求最大公因數，再用以下公式算出最小公倍數。

```text
lcm(a, b) = (a ÷ gcd(a, b)) × b
```

`gcd(a, b)` 是 `a` 的因數，所以 `a ÷ gcd(a, b)` 可以整除。

如果有三個以上的數，先算前兩個數的 LCM，再把結果與下一個數合併，直到所有數字都處理完。沿用 `[4, 6, 8]` 的例子：

1. `gcd(4, 6) = 2`，所以 `lcm(4, 6) = (4 ÷ 2) × 6 = 12`。
2. `gcd(12, 8) = 4`，所以 `lcm(12, 8) = (12 ÷ 4) × 8 = 24`。

因此 `lcm([4, 6, 8]) = 24`，與列舉倍數得到的結果相同。

### 代入題目公式

`[4, 6, 8]` 的元素乘積是 `4 × 6 × 8 = 192`，最小公倍數乘上最大公因數是 `24 × 2 = 48`。兩邊數值不同，因此 `[4, 6, 8]` 不符合乘積等價條件。

## 範例

### 範例一

- 輸入：`nums = [1, 2, 1, 2, 1, 1, 1]`
- 輸出：`5`
- 說明：取最後五個元素 `[1, 2, 1, 1, 1]`。乘積為 `2`，最小公倍數為 `2`，最大公因數為 `1`，滿足 `2 = 2 × 1`。

### 範例二

- 輸入：`nums = [2, 3, 4, 5, 6]`
- 輸出：`3`
- 說明：取中間三個元素 `[3, 4, 5]`。乘積為 `60`，最小公倍數為 `60`，最大公因數為 `1`，滿足 `60 = 60 × 1`。

### 範例三

- 輸入：`nums = [1, 2, 3, 1, 4, 5, 1]`
- 輸出：`5`
- 說明：取最後五個元素 `[3, 1, 4, 5, 1]`。乘積為 `60`，最小公倍數為 `60`，最大公因數為 `1`，滿足 `60 = 60 × 1`。

## 輸入限制

- `2 <= nums.length <= 100`（陣列包含 2 到 100 個元素）。
- `1 <= nums[i] <= 10`（每個元素都是 1 到 10 的整數）。
