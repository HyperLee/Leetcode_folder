# 3411. 最長乘積等價子陣列

英文題名為 **Maximum Subarray With Equal Products**。

## 題目說明

給定正整數陣列 `nums`，找出最長的乘積等價子陣列並回傳長度。子陣列是原陣列中索引連續的一段。若該區間的所有元素乘積等於最小公倍數（LCM）乘上最大公因數（GCD），就稱為乘積等價。

```text
prod(arr) == lcm(arr) * gcd(arr)
```

輸入限制為 `2 <= nums.Length <= 100`，每個元素滿足 `1 <= nums[i] <= 10`。

| 輸入 | 輸出 | 一個符合條件的最長子陣列 |
| --- | ---: | --- |
| `[1, 2, 1, 2, 1, 1, 1]` | 5 | `[1, 2, 1, 1, 1]`，`2 = 2 × 1` |
| `[2, 3, 4, 5, 6]` | 3 | `[3, 4, 5]`，`60 = 60 × 1` |
| `[1, 2, 3, 1, 4, 5, 1]` | 5 | `[3, 1, 4, 5, 1]`，`60 = 60 × 1` |

完整題意與 GCD、LCM 的入門例子見 [Problem_Description.md](Problem_Description.md)。

## 解題概念

### 逐步更新 GCD 與 LCM

對正整數 `a`、`b`，歐幾里得演算法使用 `gcd(a, b) = gcd(b, a % b)`。重複取餘數，直到第二個數為 `0`，此時第一個數就是最大公因數。因為 `a × b = gcd(a, b) × lcm(a, b)`，LCM 可用 `(a / gcd(a, b)) × b` 算出。除法是整除。

區間向右加入一個元素時，把它與原有的 GCD、LCM 分別套入上述更新式，就能得到新區間的兩個值。舉例來說，`[3, 4]` 的 LCM 是 `12`，加入 `5` 後用 `(12 / gcd(12, 5)) × 5` 得到 `60`。

#### GCD 的兩種寫法

本專案的兩種解法共用 `private int GCD2(int a, int b)`。它先用 `remainder` 保存 `a % b`，再把舊的 `b` 放進 `a`，最後把餘數放進 `b`。

如果要接受 `long` 參數，也可以用以下寫法。它先用 `temp` 保存舊的 `b`，再用餘數更新 `b`，最後把 `temp` 放進 `a`。

```csharp
private long Gcd(long a, long b)
{
    while (b != 0)
    {
        long temp = b;
        b = a % b;
        a = temp;
    }

    return a;
}
```

兩種寫法每輪都把 `(a, b)` 更新成 `(舊 b, 舊 a % 舊 b)`。例如傳入 `12` 和 `8`，兩者都依序走過 `(12, 8) → (8, 4) → (4, 0)`，回傳最大公因數 `4`。對相同的輸入，兩種順序執行相同輪數，每輪都只算一次 `%`。`int` 和 `long` 則決定參數與回傳值的數值範圍。

### 區間長度與質因數

任意兩個正整數的乘積都等於兩數的 GCD 乘上 LCM。題目至少有兩個元素，因此答案至少為 `2`，枚舉時也可以從長度 `2` 開始。

對長度至少為 `3` 的區間，任選一個質數 `p`。把 `p` 在每個元素中的指數由小到大排列為 `e₁, e₂, …, eₖ`。元素沒有這個因數時，指數為 `0`。

| 算式 | 質數 `p` 的指數 |
| --- | --- |
| 元素乘積 | `e₁ + e₂ + … + eₖ` |
| 最大公因數 | `e₁` |
| 最小公倍數 | `eₖ` |
| 最大公因數乘上最小公倍數 | `e₁ + eₖ` |

乘積等價要求每個質數兩側的指數都相同。因此每個質數的中間指數都必須為 `0`，也就是 `e₂ + … + eₖ₋₁ = 0`。以質數 `2` 為例，`[2, 4, 5]` 的指數排序後為 `[0, 1, 2]`，中間的 `1` 造成兩側指數不同。若一個質數出現在至少兩個元素，第二大的指數一定大於 `0`，而且在長度至少為 `3` 時一定落在中間。反過來，若每個質數至多出現在一個元素，所有中間指數都是 `0`，兩側自然相等。

所以對長度至少為 `3` 的區間，**乘積等價恰好等同於任意兩個元素都互質**。`1` 沒有質因數，可出現多次。

## 解法一　枚舉子陣列（`MaxLength`）

### 設計與正確性

1. 固定左端索引 `i`，以 `nums[i]` 初始化乘積 `prodVal`、最大公因數 `gcdVal` 與最小公倍數 `lcmVal`。
2. 右端索引 `j` 從 `i + 1` 開始。每次加入 `nums[j]`，沿用上一輪的三個數值更新區間。
3. 若 `prodVal > gcdVal * lcmVal`，用 `break` 結束這個起點的內層迴圈，外層繼續檢查下一個起點。若兩邊相等，用 `j - i + 1` 更新目前最佳長度 `res`。

#### 沿用上一輪的區間數值

固定左端 `i`，加入 `nums[j]` 前，三個變數存的是索引 `i` 到 `j - 1` 這段區間的乘積、GCD 和 LCM。加入新元素時，每一行都用該變數原本的值算出新結果。

```csharp
prodVal = prodVal * nums[j];
gcdVal = GCD2(gcdVal, nums[j]);
lcmVal = lcmVal * nums[j] / GCD2(lcmVal, nums[j]);
```

例如目前區間是 `[4, 6]`，下一個元素是 `8`。

| 變數 | 舊值 | 加入 `8` 後的計算 |
| --- | ---: | --- |
| `prodVal` | 24 | 舊乘積乘上新元素，`24 × 8 = 192` |
| `gcdVal` | 2 | 舊 GCD 和新元素一起取 GCD，`GCD2(2, 8) = 2` |
| `lcmVal` | 12 | 舊 LCM 和新元素一起取 LCM，`12 × 8 ÷ GCD2(12, 8) = 24` |

第三行要找的是 `12` 和 `8` 的最小公倍數。能同時被 `4` 和 `6` 整除的數都是 `12` 的倍數，因此把舊 LCM `12` 和新元素 `8` 代入公式，分母就是兩者的最大公因數 `GCD2(12, 8) = 4`。第二行得到的 `2` 是整段 `[4, 6, 8]` 的 GCD，後續會用它與新的 LCM 相乘來檢查題目等式。

#### 為什麼可以停止延伸？

固定左端 `i`，令 `P` 代表目前的乘積、`G` 代表 GCD、`L` 代表 LCM。因為 `L` 是正數，等式 `P = G × L` 可以兩邊同除以 `L`，改成比較 `P / L` 和 `G`。剪枝發生在 `P / L > G` 時。

現在右端多加入一個正整數 `x`。設 `d = gcd(L, x)`，也就是原有 LCM 與新元素的最大公因數。加入後的三個值如下。

```text
新乘積 P' = P × x
新 LCM L' = L × x / d
新 GCD G' = gcd(G, x)
```

把前兩式相除，分子和分母裡的 `x` 抵消。

```text
P' / L' = (P × x) / (L × x / d)
        = (P / L) × d
```

因此 `P / L` 每次都乘上一個至少為 `1` 的整數，只會維持或變大。若 `d = 1`，乘積和 LCM 都乘上同一個 `x`，比值維持原樣。若 `d > 1`，LCM 的更新多除了一個 `d`，所以比值會變大。另一方面，`G' = gcd(G, x)` 是 `G` 的因數，最多等於 `G`。

一旦目前的比值嚴格大於 `G`，再加入任何正整數後，仍會有 `P' / L' ≥ P / L > G ≥ G'`。中間的嚴格大於會一直成立，所以同一起點的任何更長區間都無法恢復等式。

#### 固定左端為 `2` 逐步驗算

以 `[2, 3, 4, 5, 6]` 為例，固定 `i = 0`。程式先用 `2` 初始化 `P`、`G` 與 `L`，接著從 `3` 開始加入。

1. **加入 `3`，得到 `[2, 3]`。** 乘積是 `2 × 3 = 6`，GCD 是 `gcd(2, 3) = 1`，LCM 是 `2 × 3 / gcd(2, 3) = 6`。此時 `P / L = 6 / 6 = 1`，與 GCD 相等，因此記下長度 `2`。
2. **加入 `4`，得到 `[2, 3, 4]`。** 乘積是 `6 × 4 = 24`，GCD 是 `gcd(1, 4) = 1`。原 LCM 是 `6`，`gcd(6, 4) = 2`，因此新 LCM 是 `6 × 4 / 2 = 12`。比值從 `1` 變成 `24 / 12 = 2`，已大於 GCD 的 `1`。原式也可直接看出 `24 > 1 × 12`，所以程式在這裡執行 `break`。
3. **假設繼續加入 `5`，得到 `[2, 3, 4, 5]`。** 乘積變成 `24 × 5 = 120`。由於 `gcd(12, 5) = 1`，LCM 也乘上 `5`，變成 `12 × 5 / 1 = 60`。比值仍是 `120 / 60 = 2`，GCD 仍是 `gcd(1, 5) = 1`。因此 `120 > 1 × 60`，依然不相等。
4. **假設再加入 `6`，得到 `[2, 3, 4, 5, 6]`。** 乘積變成 `120 × 6 = 720`。由於 `gcd(60, 6) = 6`，LCM 是 `60 × 6 / 6 = 60`，維持原值。比值從 `2` 增為 `720 / 60 = 12`，GCD 仍是 `gcd(1, 6) = 1`，所以 `720 > 1 × 60`。

後兩步是為了驗算而展開的區間。程式在第二步就已能確認，左端固定為 `2` 時，後續的比值至少為 `2`，GCD 最多為 `1`。外層迴圈接著改從 `i = 1` 的 `3` 起算，仍會找到符合條件的 `[3, 4, 5]`。

#### 計算範圍

在本題限制下，區間的 LCM 至多為 `lcm(1, 2, …, 10) = 2520`，GCD 至多為 `10`。上一輪若還能繼續，表示當時的乘積不超過 `GCD × LCM`，因此最多是 `25,200`。下一次乘入的元素最多為 `10`，檢查剪枝前的 `prodVal` 至多為 `252,000`。更新 `lcmVal` 時，先乘再除的中間值也至多為 `2520 × 10 = 25,200`。這些值都小於 `int.MaxValue` 的 `2,147,483,647`，因此三個變數都可以用 `int`。`prodVal` 的上界依賴現有的剪枝條件。

### 範例演示

輸入為 `[2, 3, 4, 5, 6]`。表中 `res` 是所有起點共用的最佳長度，初始為 `0`。每換一個起點，三個區間值都以該起點的元素重新初始化。

| `i` | `j` | 子陣列 | 乘積 | GCD | LCM | GCD × LCM | 動作 | `res` |
| ---: | ---: | --- | ---: | ---: | ---: | ---: | --- | ---: |
| 0 | 1 | `[2, 3]` | 6 | 1 | 6 | 6 | 相等，更新答案 | 2 |
| 0 | 2 | `[2, 3, 4]` | 24 | 1 | 12 | 12 | 乘積較大，停止延伸 `i = 0` | 2 |
| 1 | 2 | `[3, 4]` | 12 | 1 | 12 | 12 | 相等，答案仍為 `2` | 2 |
| 1 | 3 | `[3, 4, 5]` | 60 | 1 | 60 | 60 | 相等，更新答案 | 3 |
| 1 | 4 | `[3, 4, 5, 6]` | 360 | 1 | 60 | 60 | 乘積較大，停止延伸 `i = 1` | 3 |
| 2 | 3 | `[4, 5]` | 20 | 1 | 20 | 20 | 相等，答案仍為 `3` | 3 |
| 2 | 4 | `[4, 5, 6]` | 120 | 1 | 60 | 60 | 乘積較大，停止延伸 `i = 2` | 3 |
| 3 | 4 | `[5, 6]` | 30 | 1 | 30 | 30 | 相等，答案仍為 `3` | 3 |

`i = 0` 時在 `j = 2` 提前停止，因此跳過 `[2, 3, 4, 5]` 以及 `[2, 3, 4, 5, 6]`，接著從 `i = 1` 繼續。當 `i = 4` 時已無法組成長度 `2` 的區間，內層迴圈不執行。最後回傳 `3`。

若輸入是 100 個 `10`，從索引 `0` 開始，前兩個 `10` 的乘積為 `100`，與 `GCD × LCM` 相等。加入第三個 `10` 後，乘積增為 `1000`，而 `GCD × LCM` 仍為 `100`，因此立刻停止延伸這個起點。

### 複雜度

令 `n` 為陣列長度、`M` 為元素上界。最多檢查 `O(n²)` 個區間，每次更新呼叫兩次 GCD，第二個參數最多為 `M`，所以最壞時間為 `O(n² log M)`。本題 `M = 10`，可視為 `O(n²)`。只保存目前區間的數值與索引，額外空間為 `O(1)`。

## 解法二　滑動視窗（`MaxLength2`）

### 設計與正確性

`best` 記錄目前找到的最大長度，也是最後的回傳值。題目保證至少有兩個元素，而任何相鄰兩元素都能構成乘積等價區間，所以 `best` 從 `2` 開始。之後找最長的兩兩互質視窗，涵蓋所有長度至少為 `3` 的可能答案。

- `start` 是目前視窗左端，`end` 是這輪要加入的右端點。加入 `nums[end]` 前，`product` 儲存索引 `start` 到 `end - 1` 的乘積。若 `start == end`，視窗為空，乘積為 `1`。
- 若 `GCD2(product, nums[end]) > 1`，至少有一個質數同時整除新元素和視窗內的某個元素。反覆將 `product` 除以最左元素，再將 `start` 向右移，直到 GCD 為 `1`。如果最左元素是 `1`，乘積不變，但左界仍要前進才能移到後面的衝突元素。
- GCD 為 `1` 時，把新元素乘進 `product`。此刻視窗內的元素兩兩互質，也已包含 `start` 和 `end` 兩端，所以用 `end - start + 1` 更新 `best`。

對固定的 `end`，每次縮減前都還有衝突，因此當時的左界無法形成合格視窗。更早移除的左界也不會因為向右新增元素而恢復合格，因為從該左界到右界的區間仍包含先前發生衝突的兩個元素。縮減後的第一個合格左界，對應以 `end` 結尾的最長兩兩互質區間。

兩兩互質時，視窗元素的乘積等於它們的 LCM。該值最多為 `2520`，移除元素時乘積只會維持或減少，因此可用 `int` 儲存。視窗如果縮成空區間，乘積回到 `1`，新元素便可以加入。

### 範例演示

同樣輸入 `[2, 3, 4, 5, 6]`。初始時 `start = 0`、`product = 1`、`best = 2`。

| `end` | 新元素 | 加入前的檢查與縮減 | 加入後的視窗 | 加入後的乘積 | `best` |
| ---: | ---: | --- | --- | ---: | ---: |
| 0 | 2 | `gcd(1, 2) = 1`，直接加入 | `[2]` | 2 | 2 |
| 1 | 3 | `gcd(2, 3) = 1`，直接加入 | `[2, 3]` | 6 | 2 |
| 2 | 4 | `gcd(6, 4) = 2`，移除 `2`。剩餘乘積 `3` 與 `4` 互質 | `[3, 4]` | 12 | 2 |
| 3 | 5 | `gcd(12, 5) = 1`，直接加入 | `[3, 4, 5]` | 60 | 3 |
| 4 | 6 | `gcd(60, 6) = 6`，移除 `3`。`gcd(20, 6) = 2`，再移除 `4`。剩餘乘積 `5` 與 `6` 互質 | `[5, 6]` | 30 | 3 |

最後回傳 `3`。若輸入只有 `[2, 4]`，第二步會先移除 `2`，但 `best` 仍保留初始值 `2`，因為這兩個元素本身符合 `8 = 4 × 2`。

### 複雜度

每個元素加入一次，最多從左端移除一次。GCD 檢查總次數為 `O(n)`，每次的第二個參數最多為 `M`，所以時間為 `O(n log M)`。本題 `M = 10`，可視為 `O(n)`。額外空間為 `O(1)`。
