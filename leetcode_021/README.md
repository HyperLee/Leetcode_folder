## 題目說明

給定兩條已依「非遞減順序」排列的單向鏈結串列 `list1` 與 `list2`，將兩者合併成一條同樣依非遞減順序排列的串列，並回傳合併後的頭節點。

合併結果應由原本兩條串列的節點重新串接而成，不需要為每個值建立新的結果節點。

- [LeetCode 英文題目](https://leetcode.com/problems/merge-two-sorted-lists/description/)
- [力扣中文題目](https://leetcode.cn/problems/merge-two-sorted-lists/description/)

### 範例

```text
輸入：list1 = [1, 2, 4]，list2 = [1, 3, 4]
輸出：[1, 1, 2, 3, 4, 4]
```

```text
輸入：list1 = []，list2 = []
輸出：[]
```

```text
輸入：list1 = []，list2 = [0]
輸出：[0]
```

## 限制條件

- 每一條串列的節點數皆在 `[0, 50]` 範圍內。
- `-100 <= Node.val <= 100`。
- `list1` 與 `list2` 都已依非遞減順序排列。
- 任一輸入都可能是空串列，以 `null` 表示。

## 解題概念與出發點

如果兩條串列都已排序，合併後的下一個節點一定是兩個「目前頭節點」中較小的那一個。因此不需要先把所有值取出後重新排序，只要同時觀察兩條串列尚未處理的開頭即可。

假設目前狀態為：

```text
list1 = [1, 2, 4]
list2 = [1, 3, 4]
```

比較兩個頭節點 `1` 與 `1`，選出其中一個作為結果的第一個節點；被選取的串列往後移一格，另一條串列留在原位。重複這個步驟，就能保證每次加入結果的值都不小於前一個值。

兩種實作都遵守同一個不變條件：

> 已串接到結果中的節點保持排序，而兩條輸入指標分別指向各自尚未處理的第一個節點。

差別只在於「剩餘問題」如何被保存：

- 遞迴法交給下一層函式呼叫處理。
- 迭代法用 `while`、`tail`、`list1` 與 `list2` 指標自行保存狀態。

> [!IMPORTANT]
> 兩種解法都會修改輸入節點的 `next`，也就是重用並重新串接原串列。測試同一案例的兩種解法時，必須分別建立獨立輸入，不能讓第二種解法沿用已被第一種解法修改的串列。

## 解法一：遞迴

### 設計說明

`MergeTwoLists` 把合併工作拆成兩部分：

1. 決定目前結果串列的頭節點。
2. 遞迴合併尚未被選取的節點，再把結果接到目前頭節點之後。

終止條件是其中一條串列為空：

- `list1` 與 `list2` 都是 `null` 時，回傳 `null`。
- `list1` 是 `null` 時，直接回傳 `list2`。
- `list2` 是 `null` 時，直接回傳 `list1`。

因為非空的另一條串列本來就已排序，所以不必繼續逐節點比較，直接把整段剩餘串列交給上一層即可。

一般情況則比較 `list1.val` 與 `list2.val`：

- 若 `list1.val <= list2.val`，令 `list1.next` 指向 `MergeTwoLists(list1.next, list2)`，再回傳 `list1`。
- 否則令 `list2.next` 指向 `MergeTwoLists(list1, list2.next)`，再回傳 `list2`。

比較相等時優先選擇 `list1`，讓判斷規則保持固定；無論相等時選哪一側，數值排序結果都相同。

### 虛擬碼

```text
MergeTwoLists(list1, list2):
    如果 list1 與 list2 都是空：
        回傳空
    如果 list1 是空：
        回傳 list2
    如果 list2 是空：
        回傳 list1

    如果 list1.val <= list2.val：
        list1.next = MergeTwoLists(list1.next, list2)
        回傳 list1

    list2.next = MergeTwoLists(list1, list2.next)
    回傳 list2
```

### 範例演示流程

輸入：

```text
list1 = [1, 2, 4]
list2 = [1, 3, 4]
```

遞迴向下展開：

| 層級 | 比較 | 選擇 | 剩餘問題 |
|---:|---|---|---|
| 1 | `1 <= 1` | `list1` 的 `1` | 合併 `[2, 4]` 與 `[1, 3, 4]` |
| 2 | `2 > 1` | `list2` 的 `1` | 合併 `[2, 4]` 與 `[3, 4]` |
| 3 | `2 <= 3` | `list1` 的 `2` | 合併 `[4]` 與 `[3, 4]` |
| 4 | `4 > 3` | `list2` 的 `3` | 合併 `[4]` 與 `[4]` |
| 5 | `4 <= 4` | `list1` 的 `4` | 合併 `[]` 與 `[4]` |
| 6 | `list1` 為空 | 直接回傳 `list2` | `[4]` |

呼叫回收時，各層把選出的節點接到下一層結果之前：

```text
[4]
[4, 4]
[3, 4, 4]
[2, 3, 4, 4]
[1, 2, 3, 4, 4]
[1, 1, 2, 3, 4, 4]
```

### 複雜度

- 時間複雜度：`O(m + n)`，每個節點最多被選取一次。
- 額外空間複雜度：`O(m + n)`，最壞情況下遞迴呼叫堆疊包含所有節點。

## 解法二：迭代與虛擬頭節點

### 設計說明

`MergeTwoLists2` 使用一個不屬於答案資料的虛擬頭節點 `dummy`。`tail` 起初指向 `dummy`，之後永遠指向目前合併結果的最後一個節點。

虛擬頭節點的用途是統一「第一次串接」與後續串接：

- 不使用 `dummy` 時，第一次選出節點後還要額外設定真正的頭節點。
- 使用 `dummy` 後，每一次都只需要執行 `tail.next = selected`，最後回傳 `dummy.next`。

只要 `list1` 與 `list2` 都不是空，就持續比較兩個目前節點：

1. 選出值較小的節點 `selected`。
2. 將被選取的串列指標往後移。
3. 令 `tail.next = selected`。
4. 將 `tail` 移到 `selected`。

迴圈結束代表至少有一條串列已耗盡。另一條串列剩餘部分本來就已排序，而且其所有節點都不小於目前結果尾端，因此可以一次執行 `tail.next = list1 ?? list2`，不必再逐節點處理。

### `??` 運算子補充說明

`??` 是 C# 的 Null 聯合運算子（null-coalescing operator）。`a ?? b` 表示：如果 `a` 不是 `null`，就使用 `a`；否則使用 `b`。因此：

```csharp
tail.next = list1 ?? list2;
```

等同於：

```csharp
tail.next = list1 is not null ? list1 : list2;
```

這個迴圈結束時至少有一條串列已經是 `null`，所以這行程式會處理以下三種情況：

- `list1` 尚有節點：將 `list1` 的剩餘部分接到 `tail.next`。
- `list1` 已耗盡：將 `list2` 的剩餘部分接到 `tail.next`。
- `list1` 與 `list2` 都是 `null`：將 `tail.next` 設為 `null`，表示結果串列已到結尾。

`??` 本身不會比較或合併節點；它只負責在兩個串列參考中選出第一個不是 `null` 的值。

### 虛擬碼

```text
MergeTwoLists2(list1, list2):
    dummy = 新節點
    tail = dummy

    當 list1 與 list2 都不是空：
        如果 list1.val <= list2.val：
            selected = list1
            list1 = list1.next
        否則：
            selected = list2
            list2 = list2.next

        tail.next = selected
        tail = selected

    tail.next = 尚未耗盡的串列
    回傳 dummy.next
```

### 範例演示流程

輸入：

```text
list1 = [1, 2, 4]
list2 = [1, 3, 4]
```

| 步驟 | `list1` 目前值 | `list2` 目前值 | 選擇 | 已合併結果 |
|---:|---:|---:|---|---|
| 初始 | 1 | 1 | 尚未選擇 | `[]` |
| 1 | 1 | 1 | `list1` 的 `1` | `[1]` |
| 2 | 2 | 1 | `list2` 的 `1` | `[1, 1]` |
| 3 | 2 | 3 | `list1` 的 `2` | `[1, 1, 2]` |
| 4 | 4 | 3 | `list2` 的 `3` | `[1, 1, 2, 3]` |
| 5 | 4 | 4 | `list1` 的 `4` | `[1, 1, 2, 3, 4]` |
| 收尾 | 空 | 4 | 接上 `list2` 剩餘部分 | `[1, 1, 2, 3, 4, 4]` |

### 複雜度

- 時間複雜度：`O(m + n)`，每個節點最多被走訪一次。
- 額外空間複雜度：`O(1)`，只使用固定數量的節點參考；`dummy` 是單一輔助節點。

## 解法比較

| 面向 | 遞迴法 `MergeTwoLists` | 迭代法 `MergeTwoLists2` |
|---|---|---|
| 核心想法 | 選出較小頭節點，遞迴合併剩餘部分 | 用 `tail` 逐步串接較小節點 |
| 時間複雜度 | `O(m + n)` | `O(m + n)` |
| 額外空間 | `O(m + n)` 遞迴堆疊 | `O(1)` |
| 空串列處理 | 透過遞迴終止條件直接回傳另一側 | 跳過迴圈並在收尾接上另一側 |
| 可讀性 | 接近問題的數學定義，程式精簡 | 狀態變化明確，沒有深層呼叫堆疊 |
| 輸入節點 | 重用並重新串接 | 重用並重新串接 |

若重視程式精簡與遞迴思維，可以選擇解法一；若希望避免長串列造成較深的呼叫堆疊，解法二通常更穩健。
