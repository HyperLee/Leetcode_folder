## 題目說明

給定一個只包含 `0`、`1`、`2` 的整數陣列 `nums`，其中：

- `0` 代表紅色。
- `1` 代表白色。
- `2` 代表藍色。

請直接修改原陣列，使相同顏色彼此相鄰，最後依照紅、白、藍，也就是 `0、1、2` 的順序排列。題目不允許呼叫程式語言內建的排序函式。

### 官方範例

```text
輸入：nums = [2,0,2,1,1,0]
輸出：[0,0,1,1,2,2]
```

```text
輸入：nums = [2,0,1]
輸出：[0,1,2]
```

### 限制條件

- `n == nums.Length`
- `1 <= n <= 300`
- `nums[i]` 只能是 `0`、`1` 或 `2`
- 必須原地呈現排序結果
- 不可使用內建排序 API

進階目標是只掃描陣列一趟，並且只使用常數額外空間。

## 解題概念與出發點

這題的資料只有三種值，因此不必把它視為一般的「任意整數排序」問題。可以從三個層次思考：

1. **先求正確且容易理解**：泡沫排序直接比較相鄰元素，適合觀察排序的基本交換過程。
2. **利用值域很小**：既然只有 `0、1、2`，可以先計數，再依次寫回。
3. **進一步符合進階條件**：用指標維護已分類區間，掃描時把 `0` 放左邊、`2` 放右邊，讓 `1` 自然留在中間。

所有解法都會修改傳入的陣列。主程式在比較解法時會先複製測試資料，避免前一個解法排序過的陣列污染後續測試。

## 解法比較

| 解法 | 主要方法 | 時間複雜度 | 額外空間 | 是否單趟 | 特點 |
| --- | --- | --- | --- | --- | --- |
| 泡沫排序 | `SortColors` / `BubbleSortAlgorithm` | `O(n²)` | `O(1)` | 否 | 最直觀，但沒有利用只有三種值的條件 |
| 固定值域計數 | `SortColors2` | `O(n)` | `O(1)` | 否，兩趟 | 使用固定三格計數陣列，最簡潔的計數法 |
| 一般計數排序 | `CountingSortAlgorithm` | `O(n + k)` | `O(n + k)` | 否 | 展示累積計數與穩定回填，`k` 是值域大小 |
| 左右雙指標 | `SortColors3` | `O(n)` | `O(1)` | 是 | 把 `0` 與 `2` 推向兩端，`1` 留在中間 |
| 荷蘭國旗三指標 | `SortColors4` | `O(n)` | `O(1)` | 是 | 區間不變量最清楚，最符合題目進階要求 |

> [!NOTE]
> `SortColors` 是對外的第一種解法入口，實際排序工作委派給 `BubbleSortAlgorithm`；兩者合計視為同一種泡沫排序解法。

## 五種解法詳解

### 解法一：泡沫排序

#### 設計出發點

泡沫排序不需要知道元素只能是三種顏色。它只使用「若左邊比右邊大，就交換」這條規則，反覆把較大的值推向右端。

#### 執行方式

外層每完成一輪，尚未排序區間的最大值就會移到最右側：

1. 第一輪掃描完整陣列，把一個 `2` 推到最後。
2. 第二輪不必再比較最後一格，因為它已經定位。
3. 持續縮短範圍，直到所有元素排序完成。

#### 優缺點

- 優點：流程直觀、原地排序、不需額外陣列。
- 缺點：最差與平均時間都是 `O(n²)`，陣列較長時效率明顯落後線性解法。
- 教學價值：適合作為基準，觀察一般排序法與題目特化解法的差異。

### 解法二：固定三格計數排序

#### 設計出發點

題目保證每個元素只能是 `0`、`1` 或 `2`，因此只需建立：

```text
counts[0] = 0 的數量
counts[1] = 1 的數量
counts[2] = 2 的數量
```

#### 執行方式

1. 第一趟掃描原陣列，累加三種顏色的數量。
2. 第二趟從陣列開頭開始，先寫完所有 `0`，再寫 `1`，最後寫 `2`。
3. 每寫入一次，就把對應的計數減一。

#### 優缺點

- 優點：時間為 `O(n)`，程式簡短，固定三格陣列視為 `O(1)` 空間。
- 缺點：需要兩趟處理，不符合「單趟掃描」的進階要求。
- 適用情境：值域很小且已知時，通常比一般比較排序更合適。

### 解法三：一般化穩定計數排序

#### 設計出發點

這個版本展示完整的計數排序流程，而不是只針對三種顏色直接寫回。它先找最大值，再建立足以涵蓋整個值域的計數陣列。

#### 執行方式

1. 找出輸入中的最大值 `max`。
2. 建立長度為 `max + 1` 的 `count`，統計每個值的出現次數。
3. 將 `count` 轉成累積計數；`count[x]` 代表小於或等於 `x` 的元素數量，也就是 `x` 在輸出陣列中的右邊界。
4. 從原陣列右側往左處理，把元素放入 `output[count[value] - 1]`。
5. 放入後遞減該值的累積位置，最後把 `output` 複製回原陣列。

從右向左回填可保留相同值的相對順序，因此這是穩定排序。雖然本題的相同顏色沒有額外資訊需要保留，這個流程仍能展示一般計數排序的完整結構。

#### 優缺點

- 優點：時間為 `O(n + k)`，並且是穩定排序。
- 缺點：需要 `output` 與 `count`，額外空間為 `O(n + k)`，不符合常數空間要求。
- 適用情境：整數值域不大，而且需要穩定排序時。

### 解法四：左右雙指標

#### 設計出發點

`SortColors3` 使用兩個邊界：

- `p0`：下一個 `0` 應放置的位置。
- `p2`：下一個 `2` 應放置的位置。

掃描指標 `i` 從左向右前進。遇到 `2` 時把它交換到右側，遇到 `0` 時把它交換到左側。

#### 關鍵判斷

當 `nums[i] == 2` 時，從 `p2` 換回來的值尚未分類，可能仍然是 `2`。因此不能立刻讓 `i` 前進，而要用 `while` 在原位置繼續檢查，直到目前值不再是 `2`。

完成右側處理後：

- 若目前值是 `0`，交換到 `p0` 並推進左邊界。
- 若目前值是 `1`，不需移動，它會自然留在中間。

#### 優缺點

- 優點：`O(n)` 時間、`O(1)` 額外空間，符合進階要求。
- 缺點：交換後是否推進掃描指標需要仔細推理，否則容易漏掉尚未分類的值。

### 解法五：荷蘭國旗三指標

#### 設計出發點

`SortColors4` 直接維護四個區域：

```text
[0 ... low-1]       已分類的 0
[low ... mid-1]     已分類的 1
[mid ... high]      尚未分類
[high+1 ... n-1]    已分類的 2
```

只要 `mid <= high`，就表示仍有尚未分類的元素。

#### 三種分支

- `nums[mid] == 0`：與 `low` 交換；左側多一個確定的 `0`，所以 `low`、`mid` 都前進。
- `nums[mid] == 1`：位置已正確，只需讓 `mid` 前進。
- `nums[mid] == 2`：與 `high` 交換並讓 `high` 左移；從右側換回的值尚未分類，所以 `mid` 不能前進。

#### 優缺點

- 優點：每個元素只會被有限次數處理，時間為 `O(n)`、空間為 `O(1)`。
- 優點：區間不變量明確，是這題最典型且最符合進階要求的解法。
- 缺點：必須理解為什麼處理 `0` 後可推進 `mid`，處理 `2` 後卻不可推進。

## 範例演示流程

以下都以 `nums = [2,0,2,1,1,0]` 為例。

### 泡沫排序演示

前幾次相鄰比較會把較大的 `2` 逐步推向右側：

```text
[2,0,2,1,1,0]
 -> [0,2,2,1,1,0]
 -> [0,2,1,2,1,0]
 -> [0,2,1,1,2,0]
 -> [0,2,1,1,0,2]
```

後續輪次繼續縮小比較區間，最後得到 `[0,0,1,1,2,2]`。

### 固定三格計數演示

掃描後得到：

```text
counts = [2,2,2]
```

依序寫回兩個 `0`、兩個 `1`、兩個 `2`：

```text
[0,0,_,_,_,_]
[0,0,1,1,_,_]
[0,0,1,1,2,2]
```

### 一般計數排序演示

原始計數與累積計數為：

```text
count（次數） = [2,2,2]
count（累積） = [2,4,6]
```

累積值表示：

- `0` 的最後位置在索引 `1`。
- `1` 的最後位置在索引 `3`。
- `2` 的最後位置在索引 `5`。

從右向左依序把元素放進 `output`，完成後再複製回 `nums`。

### 左右雙指標演示

初始狀態：

```text
nums = [2,0,2,1,1,0], p0 = 0, p2 = 5
```

1. `i = 0` 遇到 `2`，與 `p2` 的 `0` 交換，得到 `[0,0,2,1,1,2]`，`p2 = 4`。
2. 同一個 `i = 0` 現在是 `0`，與 `p0` 交換，`p0 = 1`。
3. `i = 1` 是 `0`，放到下一個左側位置，`p0 = 2`。
4. `i = 2` 是 `2`，與右側 `1` 交換，得到 `[0,0,1,1,2,2]`。
5. 中間的 `1` 不需交換，排序完成。

### 荷蘭國旗演示

初始狀態：

```text
nums = [2,0,2,1,1,0], low = 0, mid = 0, high = 5
```

1. `mid` 指向 `2`：與 `high` 的 `0` 交換，得到 `[0,0,2,1,1,2]`；`high = 4`，`mid` 留在 `0`。
2. `mid` 指向 `0`：與 `low` 交換；`low = 1`、`mid = 1`。
3. 下一個值也是 `0`：交換後 `low = 2`、`mid = 2`。
4. `mid` 指向 `2`：與 `high` 的 `1` 交換，得到 `[0,0,1,1,2,2]`；`high = 3`，`mid` 不動。
5. 接著兩個 `1` 只需推進 `mid`，直到 `mid > high`。
