# 0-1 背包入門

## 每件物品只能選一次

想像你有一個最多能裝 5 公斤的背包，桌上有幾件物品。每件物品都有重量和價值，你可以選擇要帶哪些物品。目標是在總重量不超過容量的情況下，讓總價值最大。背包可以留空間。

「0-1」說的是對**每件物品**只有兩個選擇：`0` 代表不選，`1` 代表選一次。

## 用兩件物品手算

| 物品 | 重量（公斤） | 價值 |
| --- | ---: | ---: |
| A | 2 | 3 |
| B | 3 | 4 |

動態規劃（DP）會記下每個容量上限的最佳價值。每處理一件物品，就用上一輪的結果判斷加進它是否划算。

**讀表方式。** 表頭的 `0` 到 `5` 是背包的容量上限，單位是公斤。下方每一格填的是在該容量上限下能取得的**最大總價值**。例如容量 `4` 欄在「處理 A 後」填 `3`，意思是最多能取得價值 `3`，選到的 A 實際重 2 公斤。

| 容量上限（公斤） | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 還沒處理物品 | 0 | 0 | 0 | 0 | 0 | 0 |
| 處理 A 後 | 0 | 0 | 3 | 3 | 3 | 3 |
| 再處理 B 後 | 0 | 0 | 3 | 4 | 4 | 7 |

以處理 B、容量上限為 5 的那一格為例。

- **不選 B。** 沿用上一輪容量 5 的最佳價值 `3`。
- **選 B。** B 佔 3 公斤，剩下 2 公斤。上一輪在容量 2 時的最佳價值是 `3`，再加上 B 的價值 `4`，得到 `7`。

所以容量 5 時的最佳價值是 **7**，選 A 和 B。

### 容量上限為 4 公斤時，怎麼選？

| 選法 | 總重量 | 總價值 | 放得下嗎？ |
| --- | ---: | ---: | --- |
| 只選 A | 2 公斤 | 3 | 可以 |
| 只選 B | 3 公斤 | 4 | 可以 |
| A 和 B 都選 | 5 公斤 | 7 | 超過容量上限 |

如果先放 A，會剩下 `4 - 2 = 2` 公斤。B 必須整件放入，需要 3 公斤，所以這 2 公斤裝不下 B。

「處理 A 後」表示 **A 已經可以被考慮**。輪到 B 時，仍然可以比較只選 A 和只選 B。只選 B 的價值 `4` 高於只選 A 的 `3`，所以「再處理 B 後」這一列的容量 `4` 欄填入 **`4`**。

只選 B 會剩下 `4 - 3 = 1` 公斤。容量上限允許總重量在 4 公斤以內，因此留空 1 公斤也符合條件。

## 用一個陣列記住最佳價值

`dp[b]` 代表用已處理的物品，在容量**至多**為 `b` 時能取得的最大價值。陣列一開始全是 `0`，因為還沒處理任何物品，只能選空集合。

對重量為 `weight`、價值為 `value` 的物品，當 `b >= weight` 時，`Math.Max` 會比較兩個結果。第一個參數是維持原本的最佳價值，第二個參數是留出這件物品的重量後，再加上它的價值。

```csharp
int capacity = 5;
(int Weight, int Value)[] items = [(2, 3), (3, 4)];
int[] dp = new int[capacity + 1];

foreach ((int weight, int value) in items)
{
    for (int b = capacity; b >= weight; b--)
    {
        dp[b] = Math.Max(dp[b], dp[b - weight] + value);
    }
}

// dp[capacity] 是 7。
```

### 為什麼容量要倒序更新？

只處理 A 時，觀察容量 4 和容量 2 的兩格。

| 更新方向 | 更新順序 | 容量 4 的結果 |
| --- | --- | --- |
| 倒序 | 先算 `dp[4]`，此時 `dp[2]` 仍是上一輪的 `0` | `0 + 3 = 3`，A 只選一次 |
| 正序 | 先把 `dp[2]` 更新成 `3`，稍後算 `dp[4]` 時再讀它 | `3 + 3 = 6`，A 被算了兩次 |

倒序更新時，`b - weight` 比 `b` 小，本輪還沒更新到那一格，所以讀到的是加入目前物品前的結果。

## 對照 LeetCode 3946 解法一

| 0-1 背包 | 本題的首次購買 |
| --- | --- |
| 容量上限 `b` | 分配給首次購買的預算上限 `limit` |
| 物品重量 `weight` | 買該種類第一件的單價 `price` |
| 物品價值 `value` | 首次購買取得的總件數 `firstPurchaseCount`，包含付費首件與贈品 |

題目允許花錢重複購買同一種類。背包中的每個選擇是「要不要觸發這個種類的首次購買收益」，每種最多觸發一次。解法一算完各預算上限的首次購買收益後，再用剩餘預算和最低單價計算能追加幾件付費物品。
