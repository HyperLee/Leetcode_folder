## 題目說明

給定一個 `rows × cols` 的網格，起點為 `(rStart, cStart)`，初始面向東方。從起點開始，以順時針螺旋方式依序往右、下、左、上移動，直到拜訪網格內所有 `rows × cols` 個位置。

行走過程可以暫時超出網格邊界，而且超出後仍要沿著同一條螺旋路徑前進；之後可能再次回到網格內。回傳值只記錄位於網格內的座標，並保持實際拜訪順序。

方法簽章：

```csharp
public static int[][] SpiralMatrixIII(int rows, int cols, int rStart, int cStart)
```

回傳的每個元素都是 `[row, col]`，總數必定為 `rows * cols`。

## 限制條件

依照 [LeetCode 官方題目](https://leetcode.com/problems/spiral-matrix-iii/)：

- `1 <= rows, cols <= 100`
- `0 <= rStart < rows`
- `0 <= cStart < cols`

專案依照題目契約處理合法輸入，不另外加入超出題目範圍的例外或防禦性驗證。

## 解題概念與出發點

這題的難點不是「如何在矩陣內繞圈」，而是螺旋路徑可能離開矩陣。若只在網格邊界內轉向，就會改變題目要求的行走路線。

因此演算法分開處理兩件事：

1. **行走路徑**：無論目前座標是否越界，都持續沿順時針螺旋移動。
2. **結果收集**：只有目前座標位於網格內時，才加入回傳陣列。

螺旋移動可拆成四個方向：

| `dir` | 方向 | row 變化 | column 變化 |
|---:|---|---:|---:|
| `0` | 右 | `0` | `+1` |
| `1` | 下 | `+1` | `0` |
| `2` | 左 | `0` | `-1` |
| `3` | 上 | `-1` | `0` |

程式以 `around` 保存上述方向向量，並使用 `left`、`right`、`upper`、`bottom` 四個動態邊界判斷轉向時機。每次在某個方向抵達對應邊界後，切換到下一個方向，同時把該邊界向外推一格，讓下一圈比上一圈更大。

> [!NOTE]
> `row` 表示上下位置，向下時遞增；`column` 表示左右位置，向右時遞增。

## 解法設計：動態四邊界模擬

本專案目前只有一種解法，直接模擬螺旋行走。

### 1. 建立固定大小的結果陣列

合法座標總數已知為 `rows * cols`，所以先建立同樣長度的 `int[][]`。`num` 表示下一個合法座標應寫入的位置；當 `num` 超過 `rows * cols` 時，代表所有格子都已收集完成。

### 2. 從起點與第一個外圈邊界開始

目前座標初始化為：

```text
x, y = rStart, cStart
```

四個轉向邊界初始化在起點四周：

```text
left   = cStart - 1
right  = cStart + 1
upper  = rStart - 1
bottom = rStart + 1
```

初始方向為右。這些邊界不是網格的固定外框，而是目前螺旋圈的轉向位置。

### 3. 只收錄合法座標

每輪先檢查：

```text
0 <= x < rows
0 <= y < cols
```

條件成立才把 `[x, y]` 放入結果。若座標越界，不增加 `num`，但仍繼續判斷轉向並移動到下一個位置。

### 4. 到達邊界時轉向並擴張

- 向右抵達 `right`：改向下，`right` 加一。
- 向下抵達 `bottom`：改向左，`bottom` 加一。
- 向左抵達 `left`：改向上，`left` 減一。
- 向上抵達 `upper`：改向右，`upper` 減一。

這個規則讓路徑依序形成愈來愈大的矩形外圈，並保持右、下、左、上的順時針順序。

### 5. 終止條件

演算法不以目前座標是否越界作為終止依據，而是以已收集的合法座標數量判斷：

```text
num > rows * cols
```

因此即使網格是單列或單欄，路徑暫時離開網格後仍能繞回尚未拜訪的位置。

## 範例演示流程

### 範例一：`1 × 4`，由左端出發

輸入：

```text
rows = 1, cols = 4, rStart = 0, cStart = 0
```

網格只有一列，起點位於最左側。初始方向向右，所以前四個位置都在網格內：

| 步驟 | 目前座標 | 是否在網格內 | 結果 |
|---:|---|---|---|
| 1 | `(0,0)` | 是 | `[[0,0]]` |
| 2 | `(0,1)` | 是 | `[[0,0],[0,1]]` |
| 3 | `(0,2)` | 是 | `[[0,0],[0,1],[0,2]]` |
| 4 | `(0,3)` | 是 | `[[0,0],[0,1],[0,2],[0,3]]` |

已收集 `1 * 4 = 4` 個合法座標，立即結束：

```text
[[0,0],[0,1],[0,2],[0,3]]
```

### 範例二：`3 × 3`，由中心出發

輸入：

```text
rows = 3, cols = 3, rStart = 1, cStart = 1
```

起點位於中心。路徑依序向右、向下、向左、向上，再擴張到下一圈：

| 收錄順序 | 座標 | 方向／原因 |
|---:|---|---|
| 1 | `(1,1)` | 收錄起點 |
| 2 | `(1,2)` | 向右 |
| 3 | `(2,2)` | 抵達右邊界後向下 |
| 4 | `(2,1)` | 抵達下邊界後向左 |
| 5 | `(2,0)` | 繼續向左 |
| 6 | `(1,0)` | 抵達左邊界後向上 |
| 7 | `(0,0)` | 繼續向上 |
| 8 | `(0,1)` | 抵達上邊界後向右 |
| 9 | `(0,2)` | 繼續向右，收集完成 |

結果：

```text
[[1,1],[1,2],[2,2],[2,1],[2,0],[1,0],[0,0],[0,1],[0,2]]
```

這個案例可以看出：轉向邊界會在每次轉彎後向外擴張，而結果順序由實際行走路徑決定。

## 複雜度分析

令 `d = max(rows, cols)`：

- **時間複雜度：`O(d²)`**
  - 螺旋半徑最多擴張到足以覆蓋最遠角落，其總行走步數與外接正方形面積同階。
  - 路徑可能在網格外行走，因此對細長網格而言，時間不能直接寫成 `O(rows * cols)`。
- **額外空間複雜度：`O(1)`**
  - 除回傳結果外，只使用固定長度方向陣列、四個邊界與少量計數變數。
- **輸出空間複雜度：`O(rows * cols)`**
  - 回傳陣列必須保存每個網格位置的 `[row, col]`。
