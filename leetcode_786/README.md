## 題目說明

給定一個嚴格遞增的整數陣列 `arr`。陣列由 `1` 與若干不重複質數組成。對所有滿足 `0 <= i < j < arr.Length` 的索引，可以建立分數：

`arr[i] / arr[j]`

將所有分數由小到大排列後，回傳第 `k` 小分數的分子與分母：

`[arr[i], arr[j]]`

題目連結：[786. K-th Smallest Prime Fraction](https://leetcode.com/problems/k-th-smallest-prime-fraction/)

### 官方範例

- `arr = [1, 2, 3, 5], k = 3`，所有分數排序後為 `1/5, 1/3, 2/5, 1/2, 3/5, 2/3`，答案是 `[2, 5]`。
- `arr = [1, 7], k = 1`，唯一的分數是 `1/7`，答案是 `[1, 7]`。

### 限制條件

- `2 <= arr.Length <= 1000`
- `1 <= arr[i] <= 3 * 10^4`
- `arr[0] == 1`
- `arr[i]` 在 `i > 0` 時為質數
- 所有元素互不相同，並依嚴格遞增順序排列
- `1 <= k <= arr.Length * (arr.Length - 1) / 2`

本專案依照題目契約處理合法輸入，不另外加入參數驗證。

## 解題出發點

長度為 `n` 的陣列可以建立：

`n * (n - 1) / 2`

個合法分數。最直接的想法是建立全部分數、排序並取得第 `k - 1` 個元素。這種方法容易驗證，但需要保存所有組合。

進一步觀察固定分母 `arr[j]` 時：

`arr[0] / arr[j] < arr[1] / arr[j] < ... < arr[j - 1] / arr[j]`

每個分母都會形成一條已排序序列。因此可以使用最小堆合併這些序列，只取出前 `k` 個候選值，不必建立全部分數。

## 核心觀念：精確比較分數

若要比較兩個正分數 `a / b` 與 `c / d`，直接轉成 `double` 可能受到浮點表示誤差影響。因為分母皆為正數，可以改用交叉相乘：

- `a / b < c / d`
- 等價於 `a * d < c * b`

例如比較 `2/5` 與 `1/2`：

- 左側交叉乘積：`2 * 2 = 4`
- 右側交叉乘積：`1 * 5 = 5`
- 因為 `4 < 5`，所以 `2/5 < 1/2`

程式使用 `long` 保存乘積，使比較器不依賴浮點數，並提高乘法運算的安全範圍。相同的 `CompareFractions` 同時供一般排序與 `PriorityQueue` 使用，確保兩種解法採用一致的順序定義。

## 解法一：列舉所有分數後排序

### 設計說明

1. 使用兩層迴圈枚舉所有 `i < j`。
2. 將每個合法分數保存成 `[arr[i], arr[j]]`。
3. 使用交叉相乘比較器將所有分數由小到大排序。
4. 陣列索引從 `0` 開始，因此回傳排序後的第 `k - 1` 個元素。

這個方法直接建立題目定義中的完整候選集合。只要比較器能正確排列任意兩個分數，排序結果的第 `k - 1` 個元素就必然是第 `k` 小分數。

### 範例演示：`arr = [1, 2, 3, 5], k = 3`

先依 `i < j` 產生全部六個分數：

| 索引組合 | 分數 |
| --- | --- |
| `(0, 1)` | `1/2` |
| `(0, 2)` | `1/3` |
| `(0, 3)` | `1/5` |
| `(1, 2)` | `2/3` |
| `(1, 3)` | `2/5` |
| `(2, 3)` | `3/5` |

使用交叉相乘排序後：

1. `1/5`
2. `1/3`
3. `2/5`
4. `1/2`
5. `3/5`
6. `2/3`

`k = 3`，因此取得索引 `k - 1 = 2` 的 `2/5`，回傳 `[2, 5]`。

### 複雜度

令分數數量 `m = n * (n - 1) / 2`：

- 時間複雜度：建立分數需要 `O(n²)`，排序需要 `O(m log m)`，化簡為 `O(n² log n)`
- 空間複雜度：保存全部分數需要 `O(n²)`

## 解法二：最小堆合併排序序列

### 設計說明

對固定的分母索引 `j`，合法分子索引為 `0` 到 `j - 1`，而且分數會隨分子增加而遞增。解法將每個分母視為一條已排序序列：

1. 對每個 `j = 1 .. n - 1`，先把最小的 `arr[0] / arr[j]` 放入最小堆。
2. 從堆中取出目前全域最小分數 `(i, j)`。
3. 若尚未取到第 `k` 個，且 `i + 1 < j`，放入同一分母的下一個分數 `(i + 1, j)`。
4. 重複取出；第 `k` 次取出的節點就是答案。

堆中每條分母序列最多保留一個尚未處理的最小候選值。某節點被取出後，才加入同一序列的下一個節點，因此不會跳過更小的候選值。

### 正確性概念

初始化後，每條序列的第一個元素都在堆中。堆頂因此是所有序列尚未取出元素中的最小值。

取出某條序列的最小值後，只有該序列的下一個元素可能成為新的最小候選；其他序列原本的最小候選仍留在堆中。這個不變量會在每一輪維持，所以第 `k` 次取出的值正是全域第 `k` 小分數。

### 範例演示：`arr = [1, 2, 3, 5], k = 3`

每個分母形成的序列如下：

- 分母 `2`：`1/2`
- 分母 `3`：`1/3, 2/3`
- 分母 `5`：`1/5, 2/5, 3/5`

初始化堆：

`{ 1/2, 1/3, 1/5 }`

| 取出順位 | 取出值 | 推進同分母序列 | 推進後的候選值 | 說明 |
| --- | --- | --- | --- | --- |
| 1 | `1/5` | `2/5` | `1/3, 2/5, 1/2` | `1/5` 是全域最小值 |
| 2 | `1/3` | `2/3` | `2/5, 1/2, 2/3` | `1/3` 是第二小 |
| 3 | `2/5` | 不需再推進 | — | 已取得第 `k` 小分數 |

第三次取出 `2/5`，因此回傳 `[2, 5]`。

### 複雜度

- 初始化最多加入 `n - 1` 個節點
- 每次取出及加入的堆操作為 `O(log n)`
- 時間複雜度：`O((n + k) log n)`
- 空間複雜度：堆中最多保存 `n - 1` 個節點，因此是 `O(n)`

## 解法比較

| 項目 | 解法一：列舉排序 | 解法二：最小堆 |
| --- | --- | --- |
| 核心想法 | 建立完整候選集合後排序 | 合併每個分母形成的排序序列 |
| 時間複雜度 | `O(n² log n)` | `O((n + k) log n)` |
| 空間複雜度 | `O(n²)` | `O(n)` |
| 優點 | 直觀、容易理解與驗證 | 不必保存全部分數，特別適合較小的 `k` |
| 取捨 | 大型輸入會建立大量分數 | 需要理解 heap 節點與序列推進規則 |
| 分數比較 | `long` 交叉相乘 | `long` 交叉相乘 |
