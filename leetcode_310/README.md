## 題目說明

給定一棵包含 `n` 個節點的無向樹，節點編號為 `0` 到 `n - 1`，`edges[i] = [ai, bi]` 表示節點 `ai` 與 `bi` 之間有一條無向邊。

任選一個節點作為根後，樹的高度是根到最遠葉節點之間的邊數。目標是找出所有能讓樹高最小的根節點；答案最多會有兩個，順序不限。

題目來源：[LeetCode 310. Minimum Height Trees](https://leetcode.com/problems/minimum-height-trees/description/)

### 限制條件

- `1 <= n <= 2 * 10^4`
- `edges.length == n - 1`
- `0 <= ai, bi < n`
- `ai != bi`
- 所有 `(ai, bi)` 互不相同。
- 輸入保證形成一棵樹，不會有重複邊。

## 解題概念與出發點

若把根選在樹的邊緣，通往另一端的最長路徑通常很長；要讓最大深度盡可能小，根就應靠近整棵樹最長路徑的中心。

樹中任意兩點間最長的簡單路徑稱為「直徑」。最小高度樹的根必定是直徑的中點：

- 直徑包含奇數個節點時，只有一個中間節點。
- 直徑包含偶數個節點時，有兩個相鄰的中間節點。

因此問題可以拆成兩步：

1. 找到樹的直徑。
2. 取直徑路徑的中間一個或兩個節點。

## 解法：兩次 DFS 尋找樹的直徑

目前專案實作一種解法：建立鄰接表後進行兩次深度優先搜尋（DFS），再利用第二次搜尋留下的父節點關係重建直徑。

### 設計步驟

1. **處理單節點**
   - 當 `n == 1` 時，唯一節點 `0` 本身就是答案。

2. **建立鄰接表**
   - 每條邊 `[a, b]` 同時加入 `a -> b` 與 `b -> a`。
   - 之後可從任意節點走訪整棵無向樹。

3. **第一次 DFS：取得一個直徑端點**
   - 從任意節點 `0` 出發。
   - 找到距離 `0` 最遠的節點 `x`。
   - 在樹上，從任意起點找到的最遠節點必定可以作為某條直徑的端點。

4. **第二次 DFS：取得另一個直徑端點**
   - 從 `x` 再次搜尋。
   - 距離 `x` 最遠的節點 `y` 是直徑的另一端。
   - 搜尋過程同時記錄每個節點的父節點。

5. **重建直徑**
   - 從 `y` 沿父節點一路回溯至 `x`。
   - 回溯順序雖然與搜尋方向相反，仍是完整的直徑路徑。

6. **取得中心**
   - 路徑節點數為奇數：取索引 `count / 2`。
   - 路徑節點數為偶數：取索引 `count / 2 - 1` 與 `count / 2`。

### 為什麼正確

設樹的某條直徑兩端為 `x`、`y`。若根節點偏離直徑中心，根到 `x`、`y` 之中較遠端的距離一定會增加；把根移向中心則可縮短這個最大距離。因此能最小化樹高的根只能位於直徑中心。

樹的直徑若包含奇數個節點，中心唯一；若包含偶數個節點，中心是一條邊的兩端。兩次 DFS 找出直徑端點，父節點陣列重建其路徑，最後依奇偶性取中點，所以回傳值正是全部最小高度樹根節點。

### 複雜度

- **時間複雜度：`O(n)`**
  - 建立鄰接表為 `O(n)`。
  - 每次 DFS 都只走訪每個節點與每條邊一次。
  - 重建直徑最多再走訪 `n` 個節點。
- **空間複雜度：`O(n)`**
  - 鄰接表、距離、父節點與直徑路徑皆需要線性空間。
  - 遞迴 DFS 在極端長鏈上可能產生 `O(n)` 呼叫堆疊；本實作保留遞迴形式以呈現演算法，但大型或堆疊受限環境可改用顯式堆疊。

## 六組範例演示

由於題目允許答案採任意順序，範例執行器會先排序預期與實際結果，再進行比較。

### 案例 1：單一節點

- 輸入：`n = 1, edges = []`
- 不必建立直徑，唯一節點 `0` 同時是根與中心。
- 結果：`[0]`

### 案例 2：雙節點

- 輸入：`n = 2, edges = [[0, 1]]`
- 第一次 DFS 找到端點 `1`，第二次找到端點 `0`。
- 直徑路徑為 `[0, 1]`，包含偶數個節點。
- 兩個中間節點皆可使高度為 `1`。
- 結果：`[0, 1]`

### 案例 3：四節點星狀樹

- 輸入：`n = 4, edges = [[1, 0], [1, 2], [1, 3]]`
- 從 `0` 出發可找到直徑端點 `2`，再從 `2` 找到另一端 `0`。
- 回溯路徑為 `[0, 1, 2]`。
- 唯一中點是 `1`。
- 結果：`[1]`

### 案例 4：六節點題目範例

- 輸入：`n = 6, edges = [[3, 0], [3, 1], [3, 2], [3, 4], [5, 4]]`
- 從 `0` 出發找到最遠端點 `5`，再從 `5` 找到另一端 `0`。
- 回溯路徑為 `[0, 3, 4, 5]`。
- 路徑包含偶數個節點，中間兩點為 `3` 與 `4`。
- 結果：`[3, 4]`

### 案例 5：五節點長鏈

- 輸入：`n = 5, edges = [[0, 1], [1, 2], [2, 3], [3, 4]]`
- 兩次 DFS 找到端點 `4` 與 `0`。
- 直徑為 `[0, 1, 2, 3, 4]`。
- 唯一中點是 `2`。
- 結果：`[2]`

### 案例 6：六節點長鏈

- 輸入：`n = 6, edges = [[0, 1], [1, 2], [2, 3], [3, 4], [4, 5]]`
- 兩次 DFS 找到端點 `5` 與 `0`。
- 直徑為 `[0, 1, 2, 3, 4, 5]`。
- 中間兩點是 `2` 與 `3`。
- 結果：`[2, 3]`
