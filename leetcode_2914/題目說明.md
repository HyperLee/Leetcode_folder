# 2914. Minimum Number of Changes to Make Binary String Beautiful

## 題目在問什麼？

給你一個只由 `0` 和 `1` 組成的字串 `s`。你可以一次修改一個位置，把 `0` 改成 `1`，或把 `1` 改成 `0`。每改一個位置就算一次，字串的長度和字元順序維持不變。

題目要你回傳一個整數，表示讓 `s` 變成「漂亮字串」**至少需要修改幾次**。只要回傳次數即可。如果原本就符合條件，答案是 `0`。

輸入的長度介於 `2` 和 `100,000` 之間，且一定是偶數。索引從 `0` 開始，所以 `s[0]` 是第一個字元，`s[1]` 是第二個字元。

## 什麼是漂亮字串？

從左到右，把整個字串分成一段或多段。每段都取自原字串中連續的位置，且每個字元都恰好屬於一段。只要找得到一種分法，讓**每一段**同時符合下列兩個條件，這個字串就是漂亮字串。

1. **每段的長度都是偶數**，例如 2、4 或 6。
2. **同一段裡的字元都相同**，也就是整段都是 `0`，或整段都是 `1`。

下面用 `|` 標出分段的位置。

| 分段方式 | 是否符合 | 原因 |
| --- | --- | --- |
| `11 \| 00` | 符合 | 兩段的長度都是 2，各段內的字元都相同。 |
| `0000` | 符合 | 整個字串可以當成一段，長度為 4，字元都是 `0`。 |
| `10 \| 01` | 不符合 | 兩段的長度都是偶數，但每一段都混有 `0` 和 `1`。 |
| `1 \| 001` | 不符合 | 兩段的長度分別是 1 和 3，而且第二段混有 `0` 和 `1`。 |

## 官方範例

### 範例 1：`s = "1001"`，回傳 `2`

把 `s[1]`（第二個字元）由 `0` 改成 `1`，再把 `s[3]`（第四個字元）由 `1` 改成 `0`。字串從 `1001` 變成 `1100`，可以分成 `11 | 00`。兩段長度都是 2，而且各段內的字元都相同。

| 索引（從 `0` 開始） | `0` | `1` | `2` | `3` |
| --- | :---: | :---: | :---: | :---: |
| 修改前 `1001` | `1` | `0` | `0` | `1` |
| 修改後 `1100` | `1` | `1` | `0` | `0` |
| 字元變化 | — | **`0` → `1`** | — | **`1` → `0`** |

這個長度為 4 的字串只有兩種符合偶數段長的分法。若整個字串當成一段，原本有兩個 `0` 和兩個 `1`，要讓四個字元都相同，至少要改兩次。若分成兩段，原本是 `10 | 01`，兩段各需要改至少一個字元。所以只改一次不夠，而上面的修改正好用了兩次。

### 範例 2：`s = "10"`，回傳 `1`

字串長度只有 2，因此整個字串必須當成一段。原本的 `10` 同時含有 `1` 和 `0`，需要修改。把 `s[1]` 由 `0` 改成 `1`，得到合法的一段 `11`，所以最少只要改一次。

### 範例 3：`s = "0000"`，回傳 `0`

整個 `0000` 就可以當成一段，因為長度是偶數 4，且四個字元都是 `0`。原字串已經是漂亮字串，所以修改次數是 `0`。
