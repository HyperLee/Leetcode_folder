# LeetCode 2914. 使二進位字串變美麗的最少修改次數

## 題目說明

給定二進位字串 `s`，每次可以把一個位置的 `0` 改成 `1`，或把 `1` 改成 `0`。求出讓整個字串變美麗所需的最少修改次數。

美麗字串可以完整切成一段或多段連續的子字串，每段的長度都是偶數，而且每段內的字元都相同。例如 `1100` 可切成 `11 | 00`，而 `0000` 可以整串視為一段。

### 輸入限制

- `2 <= s.Length <= 100000`。
- `s.Length` 為偶數。
- `s` 只包含 `0` 和 `1`，索引從 `0` 開始。

[LeetCode 官方題面](https://leetcode.com/problems/minimum-number-of-changes-to-make-binary-string-beautiful/)

## 貪心法 `MinChanges`

### 從偶數段長找出固定配對

從索引 `0` 出發，每走完一段就前進偶數個位置，因此各段的起點與右側的切割邊界都落在偶數索引。以長度為 `8` 的字串為例，段與段之間只可能在索引 `2`、`4`、`6` 的字元前切開。

```text
Index:   0 1 | 2 3 | 4 5 | 6 7
Pair:     0  |  1  |  2  |  3
```

所以 `(0, 1)`、`(2, 3)` 等固定配對一定各自完整落在某一段裡。美麗字串的每段都由相同字元組成，配對內的兩個字元也必須相同。反過來，只要每個配對相同，就能把每組當成長度為 `2` 的合法段落。

### 為什麼逐組計數就是最小值

| 原本的配對 | 最少修改次數 | 做法 |
| --- | ---: | --- |
| `00`、`11` | 0 | 直接保留這組。 |
| `01`、`10` | 1 | 任選一個位置改成與另一個位置相同。 |

每個不相同的配對都至少要修改一個位置。各組使用的索引互不重疊，因此一次修改只能補足一組的需求。逐組各改一次便可讓所有配對相同，剛好達到這個下限。

### 程式如何掃描

1. 將累計值 `changes` 設為 `0`。
2. 從 `i = 0` 開始，比較 `s[i]` 與 `s[i + 1]`。兩者不同就把 `changes` 加 `1`。
3. 每輪以 `i += 2` 移到下一組。對合法輸入，最後一組是 `(n - 2, n - 1)`，其中 `n` 是字串長度。
4. 回傳 `changes`。演示中的修改字串用來說明成本，程式只累計次數。

掃描共比較 `n / 2` 組，時間複雜度為 **`O(n)`**，額外空間複雜度為 **`O(1)`**。

### ASCII 演示一 `1001`

```text
Index:    0 1 | 2 3
Input:    1 0 | 0 1

i     Compare    Cost    Total
0     1 != 0       1        1
2     0 != 1       1        2

10 | 01 -> 11 | 00
Return 2
```

索引 `0`、`1` 這組可以把索引 `1` 改成 `1`，索引 `2`、`3` 這組可以把索引 `3` 改成 `0`。兩組各改一次，得到合法分段 `11 | 00`。

### ASCII 演示二 `00100111`

```text
Index:    0 1 | 2 3 | 4 5 | 6 7
Input:    0 0 | 1 0 | 0 1 | 1 1

i     Compare    Cost    Total
0     0 == 0       0        0
2     1 != 0       1        1
4     0 != 1       1        2
6     1 == 1       0        2

00 | 10 | 01 | 11 -> 00 | 11 | 00 | 11
Return 2
```

第一組與最後一組已符合條件。中間兩組分別修改索引 `3` 和 `5`，累計值依序為 `0 -> 1 -> 2 -> 2`。

## 建置與執行範例

安裝 .NET 10 SDK 後，在包含本 README 的目錄執行下列指令。

```powershell
dotnet build ./leetcode_2914/leetcode_2914.csproj -c Release
dotnet run --project ./leetcode_2914/leetcode_2914.csproj -c Release --no-build
```

`Main` 會執行三筆官方案例，以及已合法分段的 `1100` 和混合相等、不相等配對的 `00100111`。其中 `10` 涵蓋最短輸入，`0000` 涵蓋全字元相同的情況。任何結果與預期不符時，對應案例會顯示 `FAIL`，且程序在跑完所有案例後以非零狀態碼結束。

```text
s = "1001" | actual = 2 | expected = 2 | PASS
s = "10" | actual = 1 | expected = 1 | PASS
s = "0000" | actual = 0 | expected = 0 | PASS
s = "1100" | actual = 0 | expected = 0 | PASS
s = "00100111" | actual = 2 | expected = 2 | PASS
```
