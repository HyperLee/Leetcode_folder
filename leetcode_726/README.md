## 題目說明

給定一個代表化學式的字串 `formula`，統計每一種元素出現的總數，最後依元素名稱的字典序輸出。

化學式遵循以下規則：

- 元素名稱以一個大寫英文字母開始，後面可以接零個或多個小寫英文字母，例如 `H`、`Mg`、`Be`。
- 元素後面可以接一個大於 `1` 的正整數，表示該元素數量；沒有數字時，數量視為 `1`。
- 多個元素或群組可以直接串接，例如 `H2O2He3Mg4`。
- 一段化學式可以放在括號內，括號後面可以接倍率，例如 `(OH)2`。
- 括號可以巢狀出現，例如 `K4(ON(SO3)2)2`。

輸出時：

1. 先依元素名稱的字典序排序。
2. 接上元素總數。
3. 數量等於 `1` 時不顯示數字。

題目連結：

- [LeetCode 726. Number of Atoms](https://leetcode.com/problems/number-of-atoms/)
- [力扣 726. 原子的数量](https://leetcode.cn/problems/number-of-atoms/)

### 官方範例

範例一：

```text
輸入：formula = "H2O"
輸出："H2O"
```

`H` 有 2 個，`O` 有 1 個；`O` 的數量為 1，因此輸出時省略數字。

範例二：

```text
輸入：formula = "Mg(OH)2"
輸出："H2MgO2"
```

括號內的 `O` 與 `H` 都要乘上 2，最後依 `H`、`Mg`、`O` 的順序輸出。

範例三：

```text
輸入：formula = "K4(ON(SO3)2)2"
輸出："K4N2O14S4"
```

內層 `(SO3)2` 必須先展開，再與外層的 `O`、`N` 合併，最後整個外層括號還要乘上 2。

## 限制條件

- `1 <= formula.Length <= 1000`
- `formula` 只包含英文字母、數字、`(` 與 `)`
- `formula` 一定是符合題目文法的有效化學式
- 測試資料保證所有輸出數量都能放入 32 位元整數

> [!NOTE]
> `CountOfAtoms` 依題目契約處理有效輸入，不額外驗證空字串、括號不成對或元素名稱格式錯誤等非法資料。

## 解題概念與出發點

困難點在於括號會建立新的計算範圍，而且倍率必須先套用在括號內所有元素，才能合併回外層。例如：

```text
(A(OH)2)3
```

必須依序完成：

1. 內層 `(OH)2` 得到 `O:2, H:2`。
2. 合併到外層後得到 `A:1, O:2, H:2`。
3. 整個外層再乘上 3，得到 `A:3, O:6, H:6`。

這種「最後進入的括號最先結束」正好符合堆疊的 LIFO（Last In, First Out）特性。因此每一層括號使用一個 `Dictionary<string, int>` 保存元素計數，再把這些字典放入 `Stack`：

```text
Stack top
┌─────────────────────┐
│ 目前括號層的元素計數 │
├─────────────────────┤
│ 外一層的元素計數     │
├─────────────────────┤
│ 最外層元素計數       │
└─────────────────────┘
```

讀到元素時，只更新堆疊頂端的字典；讀到右括號時，彈出頂端字典、乘上倍率，再合併到新的頂端。

## 解法：堆疊與每層計數字典

主要方法是 `CountOfAtoms(string formula)`。

### 使用的狀態

| 狀態 | 用途 |
| --- | --- |
| `i` | 目前解析到的字元索引 |
| `n` | 化學式長度 |
| `stack` | 保存最外層與每個尚未結束括號層的元素計數 |
| `Dictionary<string, int>` | 保存某一層的「元素名稱 → 數量」 |
| `StringBuilder` | 組合元素名稱與最後輸出 |

程式開始時先放入一個空字典，代表最外層：

```text
stack = [ {} ]
```

如此一來，不論目前是否在括號內，堆疊頂端永遠是可以累加元素的作用域。

### 判斷一：遇到左括號

讀到 `(` 時：

1. 將索引移到下一個字元。
2. 推入一個新的空字典。
3. 後續元素先記錄在這個新作用域。

```text
讀到 '(' 前：stack = [ 外層 ]
讀到 '(' 後：stack = [ 外層, 新括號層 ]
```

此時不需要立刻知道右括號後的倍率，因為倍率只有在整個群組解析完成後才會使用。

### 判斷二：遇到右括號

讀到 `)` 時：

1. 解析右括號後的連續數字。
2. 如果沒有數字，倍率預設為 `1`。
3. `Pop()` 取出剛完成的括號層。
4. 將該層每個元素的數量乘上倍率。
5. 把結果累加到 `Peek()` 取得的外層字典。

若內層是：

```text
{ H: 1, O: 1 }
```

右括號後倍率為 `2`，合併值就是：

```text
{ H: 2, O: 2 }
```

若外層原本已經有同名元素，必須累加而不是覆蓋。

### 判斷三：遇到元素

不屬於括號的字元必定是元素名稱的起點：

1. 先讀取一個大寫字母。
2. 繼續收集後面所有小寫字母，形成完整元素名稱。
3. 解析後續連續數字作為數量。
4. 沒有數字時，數量預設為 `1`。
5. 將數量累加至目前層的字典。

例如 `Be32`：

```text
元素名稱：Be
數量：32
目前層：{ Be: 32 }
```

### 多位數數量

數量可能不只一位，因此逐位使用：

```text
num = num * 10 + digit
```

解析 `32` 時：

```text
初始 num = 0
讀到 3：num = 0 * 10 + 3 = 3
讀到 2：num = 3 * 10 + 2 = 32
```

同一套邏輯同時用於元素數量與括號倍率。

### 排序與輸出

完整化學式解析完畢後，堆疊只剩最外層字典。程式將所有鍵值對依元素名稱排序，再依序附加：

```text
元素名稱 + 數量（僅當數量 > 1）
```

例如：

```text
{ Mg: 1, O: 2, H: 2 }
```

排序後為：

```text
H:2, Mg:1, O:2
```

輸出：

```text
H2MgO2
```

### 正確性理由

可以用括號層級說明：

1. 最內層括號不包含尚未完成的子群組，因此逐字累加後，其字典正確記錄該層每個元素的數量。
2. 關閉括號時，把該層所有數量乘上括號倍率，正好得到這個群組在外層貢獻的數量。
3. 將乘積累加回外層後，外層字典仍正確表示目前已解析部分的元素總數。
4. 由內向外重複此流程，最後最外層字典就是完整化學式的元素總數。
5. 最後排序只改變輸出順序，不改變計數，因此回傳格式符合題目要求。

### 複雜度

令：

- `n` 為 `formula.Length`
- `k` 為不同元素名稱的數量
- `d` 為最大括號深度
- `M` 為所有括號關閉時實際合併的字典項目總數

複雜度為：

- 逐字解析：`O(n)`
- 括號層合併：`O(M)`；每個關閉的群組都要走訪該層的不同元素
- 最終排序：`O(k log k)`
- 總時間：`O(n + M + k log k)`
- 額外空間：`O(n)`，包含所有尚未關閉作用域的字典與最後輸出

通常每個元素只參與少量層級的合併；但在深度巢狀且每層持續加入不同元素時，同一批元素可能被逐層搬移，`M` 最壞可達 `O(n × d)`，而 `d` 也可能接近 `n`，因此最壞時間上界可寫成 `O(n² + k log k)`。

## 範例演示流程

### 演示一：`Mg(OH)2`

初始狀態：

```text
stack = [ {} ]
```

1. 讀取 `Mg`

   ```text
   stack = [ { Mg: 1 } ]
   ```

2. 讀到 `(`，建立新作用域

   ```text
   stack = [ { Mg: 1 }, {} ]
   ```

3. 讀取 `O`

   ```text
   stack = [ { Mg: 1 }, { O: 1 } ]
   ```

4. 讀取 `H`

   ```text
   stack = [ { Mg: 1 }, { O: 1, H: 1 } ]
   ```

5. 讀到 `)`，解析倍率 `2`

   ```text
   括號層乘上 2：{ O: 2, H: 2 }
   合併回外層：{ Mg: 1, O: 2, H: 2 }
   ```

6. 依元素名稱排序

   ```text
   H:2, Mg:1, O:2
   ```

7. 省略 `Mg` 的數量 1，得到：

   ```text
   H2MgO2
   ```

### 演示二：`K4(ON(SO3)2)2`

1. 讀取最外層 `K4`

   ```text
   stack = [ { K: 4 } ]
   ```

2. 讀到第一個 `(`，建立外括號層，再讀取 `O`、`N`

   ```text
   stack = [
     { K: 4 },
     { O: 1, N: 1 }
   ]
   ```

3. 讀到第二個 `(`，建立內括號層，再讀取 `S`、`O3`

   ```text
   stack = [
     { K: 4 },
     { O: 1, N: 1 },
     { S: 1, O: 3 }
   ]
   ```

4. 關閉內括號並套用倍率 `2`

   ```text
   { S: 1, O: 3 } × 2
   = { S: 2, O: 6 }
   ```

   合併到上一層：

   ```text
   { O: 1, N: 1 } + { S: 2, O: 6 }
   = { O: 7, N: 1, S: 2 }
   ```

5. 關閉外括號並套用倍率 `2`

   ```text
   { O: 7, N: 1, S: 2 } × 2
   = { O: 14, N: 2, S: 4 }
   ```

   合併到最外層：

   ```text
   { K: 4, O: 14, N: 2, S: 4 }
   ```

6. 依元素名稱排序：

   ```text
   K:4, N:2, O:14, S:4
   ```

7. 最終輸出：

   ```text
   K4N2O14S4
   ```
