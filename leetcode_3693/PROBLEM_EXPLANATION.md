# LeetCode 3693 — 題目與範例理解筆記

本文整理本次討論，專注於理解題目規則、費用計算，以及題目要求的答案，不介紹演算法或程式解法。

## 1. 題目要你做什麼？

你要從第 `0` 階出發，走到第 `n` 階。每次可以往上跳 `1`、`2` 或 `3` 階，每一跳都要付費。

**題目要求：在所有合法路徑中，求出到達第 `n` 階的最小總費用。**

最後只要回傳一個數字，不需要回傳路徑，也不是計算有幾種走法。

## 2. `n` 與 `costs` 的意思

假設輸入為：

```text
n = 4
costs = [1, 2, 3, 4]

第 0 階 → 第 1 階 → 第 2 階 → 第 3 階 → 第 4 階
 起點                                      終點
```

階梯編號從 `0` 到 `4`，所以共有 `5` 個位置。你一開始就站在第 `0` 階，初始費用為 `0`。

`costs` 記錄第 `1` 階到第 `n` 階各自的落點費用：

| 階梯 | 落點費用 | 實際 C# 陣列位置 |
| --- | ---: | --- |
| 第 0 階 | 0，起點免費 | 不在陣列中 |
| 第 1 階 | 1 | `costs[0]` |
| 第 2 階 | 2 | `costs[1]` |
| 第 3 階 | 3 | `costs[2]` |
| 第 4 階 | 4 | `costs[3]` |

題目將陣列視為從 `1` 開始編號，意思是第一個數字對應第 `1` 階；C# 陣列索引則從 `0` 開始。

**階梯編號與落點費用是不同的東西。**上例只是剛好相同；如果 `costs = [5, 1, 6, 2]`，第 `2` 階的落點費用就是 `1`。

## 3. 移動規則

- 每次只能往上跳 `1`、`2` 或 `3` 階。
- 可以跳過階梯，不需要每一階都踩到。
- 必須剛好到達第 `n` 階，不能跳過終點。

以 `n = 4` 為例：

| 路徑 | 是否合法 | 原因 |
| --- | --- | --- |
| `0 → 1 → 2 → 3 → 4` | 合法 | 每次跳 1 階 |
| `0 → 2 → 4` | 合法 | 每次跳 2 階 |
| `0 → 1 → 4` | 合法 | 先跳 1 階，再跳 3 階 |
| `0 → 4` | 不合法 | 一次跳了 4 階 |

## 4. 每一跳的費用怎麼算？

```text
本次費用 = 目的階梯的落點費用 + 跳躍距離的平方
```

從第 `i` 階跳到第 `j` 階，距離為 `j - i`。題目中的公式是 `costs[j] + (j - i)²`，其中 `costs` 使用題目的 1-based 編號。

| 跳幾階 | 距離平方 | 本次費用 |
| --- | ---: | --- |
| 1 階 | `1² = 1` | 目的階梯費用 + 1 |
| 2 階 | `2² = 4` | 目的階梯費用 + 4 |
| 3 階 | `3² = 9` | 目的階梯費用 + 9 |

例如第 `4` 階的費用是 `4`，從第 `2` 階跳到第 `4` 階：

```text
跳躍距離 = 4 - 2 = 2
本次費用 = 4 + 2² = 8
```

注意以下幾點：

- **跳過的階梯不收落點費用。**從 `2 → 4`，沒有踩到第 `3` 階，就不用付它的費用。
- **每一跳都要加上距離平方。**只加落點費用，還不是完整支出。
- **起點免費，終點仍要付費。**到達第 `n` 階的最後一跳，也使用相同公式。
- **先算每一跳，再把費用加總。**不是把整趟移動的總距離平方後只算一次。

## 5. 範例一：為什麼答案是 13？

```text
n = 4
costs = [1, 2, 3, 4]

階梯：  0    1    2    3    4
費用： 起點   1    2    3    4
```

題目給的一條最佳路徑是 `0 → 1 → 2 → 4`：

| 移動 | 距離 | 落點費用 | 本次支出 |
| --- | ---: | ---: | ---: |
| `0 → 1` | 1 | 1 | `1 + 1² = 2` |
| `1 → 2` | 1 | 2 | `2 + 1² = 3` |
| `2 → 4` | 2 | 4 | `4 + 2² = 8` |

總費用為 `2 + 3 + 8 = 13`。第 `3` 階被跳過，所以不支付它的落點費用 `3`。

### 討論：走 `0 → 1 → 4`，成本沒有比較低嗎？

這條路徑合法，但總費用是 **15**：

| 移動 | 距離 | 落點費用 | 本次支出 |
| --- | ---: | ---: | ---: |
| `0 → 1` | 1 | 1 | `1 + 1² = 2` |
| `1 → 4` | 3 | 4 | `4 + 3² = 13` |

```text
總費用 = 2 + 13 = 15
```

關鍵是：**從第 `1` 階跳到第 `4` 階，跳躍距離是 `3`，所以跳躍費用為 `3² = 9`。**

兩條路徑的第一跳 `0 → 1` 相同，因此只比較後面的部分：

| 從第 1 階到第 4 階的走法 | 落點費用合計 | 跳躍距離平方合計 | 這一段總費用 |
| --- | ---: | ---: | ---: |
| `1 → 4` | `4` | `3² = 9` | 13 |
| `1 → 2 → 4` | `2 + 4 = 6` | `1² + 2² = 5` | 11 |

多踩第 `2` 階，雖然多付了落點費用 `2`，但跳躍費用從 `9` 降成 `5`，省下 `4`，最後反而便宜 `2`。

**跳的次數比較少，不代表總費用比較低。**落點費用與每一跳的距離平方都會影響總費用。

### 怎麼確認 13 確實是最小？

這個小範例的所有合法路徑如下。此處只用來核對範例答案，並非介紹一般解題演算法。

| 路徑 | 每一跳費用加總 | 總費用 |
| --- | --- | ---: |
| `0 → 1 → 2 → 3 → 4` | `2 + 3 + 4 + 5` | 14 |
| `0 → 1 → 2 → 4` | `2 + 3 + 8` | **13** |
| `0 → 1 → 3 → 4` | `2 + 7 + 5` | 14 |
| `0 → 2 → 3 → 4` | `6 + 4 + 5` | 15 |
| `0 → 2 → 4` | `6 + 8` | 14 |
| `0 → 1 → 4` | `2 + 13` | 15 |
| `0 → 3 → 4` | `12 + 5` | 17 |

`0 → 4` 一次跳了 4 階，不符合規則，因此不列入比較。所有合法路徑中，最低總費用為 **13**。

## 6. 範例二：答案為 11

```text
n = 4
costs = [5, 1, 6, 2]

階梯：  0    1    2    3    4
費用： 起點   5    1    6    2
```

最佳路徑為 `0 → 2 → 4`：

| 移動 | 距離 | 落點費用 | 本次支出 |
| --- | ---: | ---: | ---: |
| `0 → 2` | 2 | 1 | `1 + 2² = 5` |
| `2 → 4` | 2 | 2 | `2 + 2² = 6` |

```text
總費用 = 5 + 6 = 11
```

第 `1` 階和第 `3` 階沒有踩到，所以不支付它們的費用 `5`、`6`。

答案也不是只有落點費用的 `1 + 2 = 3`，還必須加上兩次跳躍的距離平方：

```text
落點費用合計 = 1 + 2 = 3
跳躍費用合計 = 2² + 2² = 8
總費用       = 3 + 8 = 11
```

## 7. 範例三：答案為 12

```text
n = 3
costs = [9, 8, 3]

階梯：  0    1    2    3
費用： 起點   9    8    3
```

最佳路徑為 `0 → 3`。一次跳 3 階符合規則，所以可以直接抵達終點：

```text
目的階梯費用 = 3
跳躍距離平方 = 3² = 9
總費用       = 3 + 9 = 12
```

第 `1` 階與第 `2` 階被跳過，不用支付費用 `9`、`8`。

若每次走一階，路徑為 `0 → 1 → 2 → 3`：

```text
總費用 = (9 + 1²) + (8 + 1²) + (3 + 1²)
       = 10 + 9 + 4
       = 23
```

這個範例中，直接跳 3 階的總費用較低。搭配範例一可以理解：跳得遠或跳得近，本身都不能直接判斷是否便宜，仍要依公式計算整條路徑的總費用。

## 8. 閱讀題目時記住這幾件事

1. 從第 `0` 階出發，起始費用為 `0`。
2. 每次只能往上跳 `1～3` 階，必須剛好到第 `n` 階。
3. 每一跳支付「目的階梯費用 + 本次跳躍距離的平方」。
4. 沒踩到的階梯不用付落點費用，終點則仍需付費。
5. 將每一跳的費用加總，才是整條路徑的總費用。
6. 題目要回傳所有合法路徑中的最小總費用，不需要回傳路徑。
