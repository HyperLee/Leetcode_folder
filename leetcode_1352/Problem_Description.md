# 1352. Product of the Last K Numbers

## 最後 K 個數的乘積

- 難度：中等（Medium）
- 官方題目：[LeetCode 1352](https://leetcode.com/problems/product-of-the-last-k-numbers/)

## 題目說明

設計一個可以接收整數資料流的類別。資料會依照加入順序累積，並且可以隨時查詢目前資料流中「最後 `k` 個數字」的乘積。

「最後 `k` 個數字」是指目前資料流最尾端、連續的 `k` 個元素。例如，目前資料流是 `[3, 0, 2, 5, 4]` 時：

- 最後 2 個數字是 `[5, 4]`。
- 最後 3 個數字是 `[2, 5, 4]`。
- 最後 4 個數字是 `[0, 2, 5, 4]`。

每次查詢都以當下的資料流為準。查詢只回傳乘積，不會移除任何數字，也不會改變資料流內容。

## 需要實作的介面

實作 `ProductOfNumbers` 類別，提供以下操作：

| 介面 | 功能 |
| --- | --- |
| `ProductOfNumbers()` | 建立物件，初始資料流為空。 |
| `void add(int num)` | 將整數 `num` 加入資料流的尾端。 |
| `int getProduct(int k)` | 回傳目前資料流最後 `k` 個數字的乘積。 |

呼叫 `getProduct(k)` 時，題目保證資料流中至少已經有 `k` 個數字，因此不需要處理資料數量不足的查詢。

資料流可能包含 `0`。如果查詢範圍包含 `0`，乘積就是 `0`；如果 `0` 位於查詢範圍之外，則不影響這次查詢的乘積。

## 限制條件

- `0 <= num <= 100`。
- `1 <= k <= 4 × 10^4`。
- `add` 與 `getProduct` 的呼叫次數合計最多為 `4 × 10^4` 次。
- 每次查詢時，目前資料流的長度至少為 `k`。
- 測試資料保證，在任何時刻，任意連續區段的數字乘積都能以單一 32 位元整數表示，不會溢位。

## 官方範例

### 輸入

```text
["ProductOfNumbers", "add", "add", "add", "add", "add", "getProduct", "getProduct", "getProduct", "add", "getProduct"]
[[], [3], [0], [2], [5], [4], [2], [3], [4], [8], [2]]
```

第一列表示依序呼叫的建構子或方法，第二列是各次操作對應的參數。例如，`"add"` 對應 `[3]` 表示呼叫 `add(3)`；`"getProduct"` 對應 `[2]` 表示呼叫 `getProduct(2)`。

建構子對應的 `[]` 表示沒有傳入參數。

### 輸出

```text
[null, null, null, null, null, null, 20, 40, 0, null, 32]
```

輸出的每個位置都對應同一位置的輸入操作。`null` 是題目測試格式對建構子與無回傳值操作的表示；只有 `getProduct` 操作會回傳整數結果。

### 逐步說明

| 步驟 | 操作 | 操作後的資料流 | 對應輸出 | 說明 |
| --- | --- | --- | --- | --- |
| 1 | `ProductOfNumbers()` | `[]` | `null` | 建立物件，資料流為空。 |
| 2 | `add(3)` | `[3]` | `null` | 將 3 加入尾端。 |
| 3 | `add(0)` | `[3, 0]` | `null` | 將 0 加入尾端。 |
| 4 | `add(2)` | `[3, 0, 2]` | `null` | 將 2 加入尾端。 |
| 5 | `add(5)` | `[3, 0, 2, 5]` | `null` | 將 5 加入尾端。 |
| 6 | `add(4)` | `[3, 0, 2, 5, 4]` | `null` | 將 4 加入尾端。 |
| 7 | `getProduct(2)` | `[3, 0, 2, 5, 4]` | `20` | 最後 2 個數字是 `[5, 4]`，乘積為 `5 × 4 = 20`。 |
| 8 | `getProduct(3)` | `[3, 0, 2, 5, 4]` | `40` | 最後 3 個數字是 `[2, 5, 4]`，乘積為 `2 × 5 × 4 = 40`。 |
| 9 | `getProduct(4)` | `[3, 0, 2, 5, 4]` | `0` | 最後 4 個數字是 `[0, 2, 5, 4]`，乘積為 `0 × 2 × 5 × 4 = 0`。 |
| 10 | `add(8)` | `[3, 0, 2, 5, 4, 8]` | `null` | 將 8 加入尾端。 |
| 11 | `getProduct(2)` | `[3, 0, 2, 5, 4, 8]` | `32` | 最後 2 個數字是 `[4, 8]`，乘積為 `4 × 8 = 32`。 |

### 範例重點

- 步驟 7 到步驟 9 之間沒有新增數字，因此三次查詢使用相同的資料流，只是查詢的尾端範圍不同。
- 步驟 7 與步驟 8 的查詢範圍不包含 0，因此結果分別為 20 與 40。
- 步驟 9 的查詢範圍包含 0，因此結果為 0。
- 步驟 10 新增 8 後，最後 2 個數字變成 `[4, 8]`，所以步驟 11 回傳 32。
