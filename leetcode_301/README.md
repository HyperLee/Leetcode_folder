## 題目說明與限制

給定只包含括號和字母的字串 `s`，移除最少數量的無效括號，使字串有效。回傳所有透過最少次數刪除得到的唯一結果，結果順序不限。字母不刪除，也不影響括號配對。

官方限制如下：

- `1 <= s.Length <= 25`
- `s` 只包含小寫英文字母、`'('` 和 `')'`
- `s` 中最多有 20 個括號

題目原文與範例可參考 [LeetCode 301](https://leetcode.com/problems/remove-invalid-parentheses/description/)。

## 有效括號的判準

從左至右掃描時，以 `balance` 記錄尚未配對的左括號數：遇到 `(` 加一，遇到 `)` 減一，遇到字母則不變。字串有效必須同時符合：

1. 每個前綴的 `balance` 都不小於零；否則該前綴有多出的右括號。
2. 掃描結束時 `balance` 等於零；否則仍有未配對的左括號。

這兩個條件也是 `IsValid` 掃描候選字串時採用的判準。

## 解法：回溯與剪枝

本專案只有一種解法。`Helper` 與 `IsValid` 是這個解法的輔助函式，不是另外兩種獨立解法。

### 1. 先算出最少要刪除幾個括號

`RemoveInvalidParentheses` 第一次掃描字串，維護 `lremove` 與 `rremove`：

- 遇到 `(`，增加 `lremove`，代表目前多出一個尚未配對的左括號。
- 遇到 `)`，若有未配對的 `(` 就配對並減少 `lremove`；否則增加 `rremove`，代表這個右括號無法配對。
- 掃描結束時，`rremove` 是多出的右括號數，剩餘的 `lremove` 是多出的左括號數。

這兩個數字固定了左右括號各自的最少刪除量，但不指定必須刪除哪些索引。回溯會枚舉符合數量的刪除位置，再由有效性檢查篩選結果；因此能保留不同的最少刪除答案，也不會多刪括號。

以 `s = "()())()"` 為例：

| 索引 | 字元 | `lremove` | `rremove` | 說明 |
| ---: | :---: | ---: | ---: | --- |
| 0 | `(` | 1 | 0 | 一個待配對左括號 |
| 1 | `)` | 0 | 0 | 與左括號配對 |
| 2 | `(` | 1 | 0 | 一個待配對左括號 |
| 3 | `)` | 0 | 0 | 與左括號配對 |
| 4 | `)` | 0 | 1 | 沒有可配對的左括號 |
| 5 | `(` | 1 | 1 | 一個待配對左括號 |
| 6 | `)` | 0 | 1 | 與左括號配對 |

因此只需移除一個右括號：`lremove = 0`、`rremove = 1`。

### 2. 回溯列舉刪除位置

`Helper(str, start, lremove, rremove)` 只在尚需移除的括號種類與數量符合時建立分支：

1. 從 `start` 開始掃描，遇到可移除的括號才建立刪除後的新字串。
2. 刪除後仍從原索引 `i` 繼續搜尋，因為後面的字元刪除後會移到這個索引；這讓刪除位置依序前進，避免用不同順序重複探索相同組合。
3. 若目前字元與前一字元相同，只嘗試其中一個刪除位置。刪除連續相同括號會得到相同候選，跳過其他位置可避免重複分支。
4. 若從目前位置起的剩餘字元數少於仍需刪除數，就提早結束該分支。即使把所有剩餘字元都刪除也不夠，因此不可能完成目標。
5. 當 `lremove` 與 `rremove` 都歸零時，呼叫 `IsValid`；通過驗證的字串加入結果清單。

### 3. 檢查候選結果

`IsValid` 逐字掃描候選字串。左括號讓餘額加一，右括號讓餘額減一；若餘額變成負數，立即判定無效。掃描結束時只有餘額等於零才有效。字母不改變餘額。

每次呼叫 `RemoveInvalidParentheses` 都會建立新的結果清單，因此同一個 `Program` 物件可以連續處理多筆輸入，且先前呼叫回傳的清單不會被後續呼叫改動。

## 範例演示

### 多個最少刪除結果：`"()())()"`

初始計算得到 `lremove = 0`、`rremove = 1`，所以每條搜尋路徑都只刪除一個右括號：

```text
刪除索引 1 的 ')'  -> (())()  -> 有效，保留
刪除索引 3 的 ')'  -> ()()()  -> 有效，保留
刪除索引 4 的 ')'  -> 與索引 3 相鄰且相同，略過重複分支
刪除索引 6 的 ')'  -> ()())(  -> 前綴出現負餘額，捨棄
```

結果為 `["(())()", "()()()"]`。兩種結果各刪除一個括號，且都符合有效括號判準。

### 輸入 `")("`，移除左右括號後得到空字串

輸入 `")("` 開頭有一個無法配對的右括號，結尾有一個未配對的左括號，因此 `rremove = 1`、`lremove = 1`。移除兩者後得到空字串；空字串沒有不平衡括號，所以是有效結果，回傳值是 `[""]`（包含一個空字串的清單）。

### 其他邊界案例

| 輸入 | 預期結果 | 說明 |
| --- | --- | --- |
| `"(a)())()"` | `["(a())()", "(a)()()"]` | 保留字母並回傳所有最少刪除結果 |
| `"(a(b)c)"` | `["(a(b)c)"]` | 原字串已有效，不需刪除 |
| `"((("` | `[""]` | 重複的未配對左括號都必須移除 |
| `"())"` | `["()"]` | 移除一個多出的右括號 |
| `"abc"` | `["abc"]` | 沒有括號時，原字串就是唯一結果 |
| `""` | `[""]` | 專案額外健壯性案例；長度 0 不在官方限制內 |

## 正確性與複雜度

- **最少刪除：** 初次掃描精確算出必須移除的左右括號數量。任一有效結果至少要刪除這些數量；回溯搜尋能找到達到此下限且通過有效性檢查的結果，因此刪除量最少。
- **完整搜尋：** `Helper` 枚舉符合左右移除數量的刪除位置組合，並只在移除數量歸零後接受 `IsValid` 確認有效的候選。
- **唯一結果：** 連續相同括號只展開一種等價刪除選擇，避免重複候選。
- **時間複雜度：** 設 `n` 為字串長度、`p` 為括號數。回溯最壞情況有指數級分支；每個分支可能掃描字串並建立新字串，保守上界為 `O(n² × 2ᵖ)`。
- **額外空間：** 不計回傳結果清單，遞迴深度最多為 `p`，遞迴中保留的候選字串最多各長 `n`，因此為 `O(n × p)`。若有 `r` 個結果，結果清單另需 `O(r × n)` 空間。
