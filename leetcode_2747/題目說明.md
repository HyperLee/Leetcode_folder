# 2747. Count Zero Request Servers 題目說明

題目連結：[LeetCode 2747](https://leetcode.com/problems/count-zero-request-servers/description/)

這題的核心是：**指定一段時間，計算有幾台伺服器在這段時間內「完全沒有收到請求」。**

可以把「請求」想成有人連線使用伺服器。題目只關心這段時間內有沒有被使用過；只要收到過一次，就不算「零請求」。

## 1. 每個輸入代表什麼？

假設輸入如下：

```text
n = 3
logs = [[1,3], [2,6], [1,5]]
x = 5
queries = [10,11]
```

### n：伺服器總數

`n = 3` 代表共有三台伺服器，編號分別是 `1、2、3`。

即使某台伺服器沒有出現在 `logs` 裡，也依然存在。

### logs：收到請求的歷史紀錄

每一筆的格式是：

```text
[伺服器編號, 收到請求的時間]
```

| 紀錄 | 意思 |
|---|---|
| `[1,3]` | 伺服器 1 在時間 3 收到一次請求 |
| `[2,6]` | 伺服器 2 在時間 6 收到一次請求 |
| `[1,5]` | 伺服器 1 在時間 5 收到一次請求 |

注意，`logs` 不一定按照時間排列。

### queries 與 x：決定檢查的時間區間

`queries = [10,11]` 代表要回答兩個問題：

- 當檢查時間是 `10` 時，有幾台伺服器符合零請求條件？
- 當檢查時間是 `11` 時，有幾台伺服器符合零請求條件？

每個查詢時間 `q`，搭配 `x`，會形成檢查區間：

```text
[q - x, q]
```

**左右兩端都包含。** 例如 `[5,10]`，時間剛好是 `5` 或 `10` 的請求都要算進去。

判斷一筆請求是否在區間內，可以寫成：

```text
q - x <= 請求時間 <= q
```

### 回傳值：每個查詢的答案

回傳陣列的長度與 `queries` 相同，答案必須保留原本的查詢順序。

```text
queries[i]：第 i 個查詢時間
答案[i]：該查詢區間內，完全沒有收到請求的伺服器數量
```

## 2. 範例一：為什麼答案是 [1,2]？

```text
n = 3
logs = [[1,3], [2,6], [1,5]]
x = 5
queries = [10,11]
```

先將紀錄按照時間整理，方便理解：

```text
時間 3：伺服器 1 收到請求
時間 5：伺服器 1 收到請求
時間 6：伺服器 2 收到請求

伺服器 3：沒有任何請求紀錄
```

### 第一個查詢：q = 10

檢查區間為：

```text
[10 - 5, 10] = [5,10]
```

逐筆判斷：

| 請求紀錄 | 是否在 `[5,10]` 內？ | 原因 |
|---|---|---|
| 伺服器 1，時間 3 | 否 | `3 < 5` |
| 伺服器 1，時間 5 | 是 | 起點也包含 |
| 伺服器 2，時間 6 | 是 | `5 <= 6 <= 10` |

因此各台伺服器的狀況如下：

| 伺服器 | 區間內是否收到請求？ |
|---|---|
| 1 | 有 |
| 2 | 有 |
| 3 | 沒有 |

只有伺服器 3 沒收到請求，因此第一個答案是 **1**。

### 第二個查詢：q = 11

檢查區間為：

```text
[11 - 5, 11] = [6,11]
```

逐筆判斷：

| 請求紀錄 | 是否在 `[6,11]` 內？ | 原因 |
|---|---|---|
| 伺服器 1，時間 3 | 否 | `3 < 6` |
| 伺服器 1，時間 5 | 否 | `5 < 6` |
| 伺服器 2，時間 6 | 是 | 起點也包含 |

因此各台伺服器的狀況如下：

| 伺服器 | 區間內是否收到請求？ |
|---|---|
| 1 | 沒有 |
| 2 | 有 |
| 3 | 沒有 |

伺服器 1、3 都沒收到請求，因此第二個答案是 **2**。

**伺服器 1 雖然以前收到過請求，但時間 3、5 都不在這次的 `[6,11]` 裡，因此這次仍然算「零請求」。**

將兩次答案按查詢順序放在一起：

```text
queries = [10,11]
答案    = [ 1, 2]
```

## 3. 範例二：為什麼答案是 [0,1]？

```text
n = 3
logs = [[2,4], [2,1], [1,2], [3,1]]
x = 2
queries = [3,4]
```

按照時間整理：

| 時間 | 哪些伺服器收到請求 |
|---|---|
| 1 | 伺服器 2、3 |
| 2 | 伺服器 1 |
| 4 | 伺服器 2 |

### 第一個查詢：q = 3

```text
檢查區間 = [3 - 2, 3] = [1,3]
```

這段時間內：

- 伺服器 1：時間 `2` 收到請求。
- 伺服器 2：時間 `1` 收到請求。
- 伺服器 3：時間 `1` 收到請求。

三台都有收到請求，所以沒有任何一台是零請求。

```text
答案 = 0
```

### 第二個查詢：q = 4

```text
檢查區間 = [4 - 2, 4] = [2,4]
```

這段時間內：

- 伺服器 1：時間 `2` 收到請求，包含左端點。
- 伺服器 2：時間 `4` 收到請求，包含右端點。
- 伺服器 3：只有時間 `1` 的紀錄，已經在區間外。

只有伺服器 3 是零請求。

```text
答案 = 1
```

因此回傳：

```text
[0,1]
```

## 4. 容易誤會的地方

| 容易混淆的地方 | 正確理解 |
|---|---|
| 是算請求的數量嗎？ | 是算「沒有收到請求的伺服器」有幾台 |
| 一台伺服器收到十次請求呢？ | 它仍然只是一台有收到請求的伺服器 |
| 以前收到過請求，就不能算零請求嗎？ | 只看這次指定區間，區間外的紀錄不影響 |
| `queries[i]` 是伺服器編號嗎？ | 它是檢查時間點 |
| `[q-x,q]` 包含兩端嗎？ | 包含，條件是 `q-x <= time <= q` |
| 每次查詢會消耗或刪除紀錄嗎？ | 不會，每次都是用同一份紀錄檢查自己的時間區間 |

## 5. 用一個公式理解答案

每次查詢都可以這樣思考：

```text
零請求伺服器數量
= 伺服器總數 n
  - 區間內至少收到一次請求的不同伺服器數量
```

例如總共有 3 台，而區間內收到請求的伺服器編號依序是：

```text
1、1、2、1、2
```

雖然有 5 筆請求，但只有 **2 台不同的伺服器**收到請求，因此答案是：

```text
3 - 2 = 1 台
```
