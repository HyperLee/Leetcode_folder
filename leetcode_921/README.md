# LeetCode 921：使括號有效的最少添加

這個專案使用 C# / .NET 10 實作 LeetCode 921「Minimum Add to Make Parentheses Valid」。
程式以貪心法從左至右掃描括號字串，計算最少需要插入多少個括號，才能讓整個字串成為有效括號字串。

題目連結：[Minimum Add to Make Parentheses Valid](https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/description/)

## 題目說明

括號字串在符合以下任一條件時是有效的：

1. 它是空字串。
2. 它可以寫成 `AB`，其中 `A` 與 `B` 都是有效括號字串。
3. 它可以寫成 `(A)`，其中 `A` 是有效括號字串。

給定只由 `(` 與 `)` 組成的字串 `s`，一次操作可以在任意位置插入一個括號。請計算讓 `s` 變成有效括號字串所需的最少操作次數。

例如，輸入 `s = "())"` 時，只要插入一個 `(`，就能得到有效字串 `"(())"`，因此答案是 `1`。

## 限制條件

- `1 <= s.length <= 1000`
- `s[i]` 只可能是 `(` 或 `)`

題目限制來自 [LeetCode 題目頁](https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/description/)。
本專案的本機 runner 另外測試空字串 `""`，用來確認方法在最小邊界情況下也能正常處理；空字串是有效括號字串，但不在上述線上輸入長度限制內。

## 解題概念與出發點

從左至右掃描時，可以用一個數字表示目前前綴的括號狀態：

- 讀到 `(`，未配對的左括號數量增加一個。
- 讀到 `)`，如果有未配對的 `(`，就讓其中一個左右括號配對。
- 讀到 `)` 時若沒有任何未配對的 `(`，這個右括號不可能被前面內容修正；無論把新 `(` 插在哪個允許位置，都至少需要增加一個括號。

因此只需要維護兩個狀態：

| 狀態 | 意義 |
| --- | --- |
| `leftCount` | 掃描目前前綴後，尚未配對的 `(` 數量 |
| `res` | 到目前為止已確定必須插入的括號數量 |

這種作法也可以理解為維護 prefix balance：`leftCount` 不會小於零；當原字串的 balance 想要變成負數時，就立刻把必要的左括號計入 `res`，讓後續狀態重新回到可繼續配對的範圍。

## 解法：貪心掃描

### 掃描流程

對字串中的每個字元依序處理：

1. 若字元是 `(`，執行 `leftCount++`。
2. 若字元是 `)` 且 `leftCount > 0`，使用一個未配對的左括號，執行 `leftCount--`。
3. 若字元是 `)` 且 `leftCount == 0`，目前沒有左括號可配對，執行 `res++`，代表必須插入一個 `(`。
4. 掃描結束後，`leftCount` 個左括號仍沒有右括號，因此把 `leftCount` 加到 `res`。

最後的答案是 `res`。

### 為什麼是最少次數

可以把必要的插入分成兩類：

1. **前綴出現多餘的 `)`**：當讀到 `)` 且 `leftCount == 0` 時，前面沒有任何左括號可以配對。要讓這個右括號出現在有效字串中，至少需要補一個 `(`，所以每次 `res++` 都是不可避免的成本。
2. **結尾剩餘的 `(`**：掃描結束後，每個未配對的 `(` 都需要一個 `)`。一個右括號只能完成一個配對，所以至少要補上 `leftCount` 個右括號。

演算法只在確定無法配對時才增加插入數量，且不會為已經可以配對的括號額外插入字元。因此兩類必要成本的總和就是最小答案。

### 程式狀態與實作對照

| 程式位置 | 狀態轉移 | 解題意義 |
| --- | --- | --- |
| `c == '('` | `leftCount++` | 多了一個等待配對的左括號 |
| `leftCount > 0` | `leftCount--` | 當前右括號與一個左括號配對 |
| `leftCount == 0` | `res++` | 補一個必要的左括號 |
| 迴圈結束 | `res += leftCount` | 為所有剩餘左括號補右括號 |

### 複雜度

- 時間複雜度：`O(n)`，每個字元只掃描一次。
- 空間複雜度：`O(1)`，只使用 `leftCount`、`res` 與少量迴圈變數。

## 範例演示流程

### 範例一：`s = "())"`

| 索引 | 字元 | 動作 | `leftCount` | `res` |
| ---: | :---: | --- | ---: | ---: |
| 0 | `(` | 累積一個未配對左括號 | 1 | 0 |
| 1 | `)` | 與左括號配對 | 0 | 0 |
| 2 | `)` | 沒有左括號可配對，補一個 `(` | 0 | 1 |

掃描結束時沒有剩餘左括號，因此答案是 `1`。

### 範例二：`s = "((("`

| 索引 | 字元 | 動作 | `leftCount` | `res` |
| ---: | :---: | --- | ---: | ---: |
| 0 | `(` | 累積一個未配對左括號 | 1 | 0 |
| 1 | `(` | 再累積一個未配對左括號 | 2 | 0 |
| 2 | `(` | 再累積一個未配對左括號 | 3 | 0 |

字串結束後有三個左括號沒有配對，因此需要補三個 `)`，答案是 `3`。

### 範例三：`s = "())(()"`

| 索引 | 字元 | 動作 | `leftCount` | `res` |
| ---: | :---: | --- | ---: | ---: |
| 0 | `(` | 累積左括號 | 1 | 0 |
| 1 | `)` | 配對 | 0 | 0 |
| 2 | `)` | 沒有左括號可配對，補一個 `(` | 0 | 1 |
| 3 | `(` | 累積左括號 | 1 | 1 |
| 4 | `(` | 再累積左括號 | 2 | 1 |
| 5 | `)` | 與一個左括號配對 | 1 | 1 |

最後還剩一個未配對的 `(`，所以再補一個 `)`；總答案為 `1 + 1 = 2`。

### 範例四：`s = "))"`

第一個 `)` 與第二個 `)` 都沒有可配對的左括號，每個都必須各補一個 `(`，因此答案是 `2`。這個案例示範了演算法如何處理前綴 balance 變成負數的情況。

## 邊界案例整理

| 輸入 | 狀況 | 最少插入數 |
| --- | --- | ---: |
| `""` | 本機額外測試的空字串；本身已有效 | 0 |
| `"()"` | 已經有效，不需修改 | 0 |
| `"))"` | 前綴連續出現沒有左括號可配對的右括號 | 2 |

| `"()))"` | 先完成一組配對，後面有兩個多餘右括號 | 2 |
