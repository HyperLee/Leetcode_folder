# 2567. Minimum Score by Changing Two Elements

修改兩個元素後的最小分數

題目來源：[LeetCode 2567](https://leetcode.com/problems/minimum-score-by-changing-two-elements/)

## 一、題目在說什麼？

給定一個整數陣列 `nums`。題目會根據陣列中各個元素之間的差距，定義三個數值：**低分（low score）**、**高分（high score）**，以及**總分（score）**。

你可以修改陣列中兩個位置的元素數值，目標是讓修改後的總分盡可能小，最後回傳這個最小總分。

這裡的「修改」是將原有位置存放的數值替換成另一個整數，**新數值不必曾經出現在原陣列中**。例如，原本存放 `1` 的位置可以改成 `6`，即使原陣列沒有 `6`。修改後陣列的元素個數維持不變。

## 二、先理解「兩個元素的絕對差」

兩個數值 `a`、`b` 的絕對差寫成 `|a - b|`，表示它們相距多遠，不考慮相減後的正負號。

例如：

- `|4 - 7| = 3`。
- `|7 - 4| = 3`，交換順序不會改變差距。
- `|6 - 6| = 0`，兩個數值相同，差距就是零。

題目中的「兩個元素」指的是**陣列中不同位置的兩個元素**。不同位置的數值可以相同，但不能拿同一個位置的元素與自己比較。

比較範圍包含陣列中所有可能的元素配對，**不只比較相鄰位置**。這裡算的是數值差距，不是兩個位置的索引差距。

## 三、低分、高分與總分分別是什麼？

### 1. 低分（low score）

把不同位置的元素兩兩配對，算出各組的絕對差，當中**最小的絕對差**就是低分。

也就是問：陣列中「數值最接近的兩個元素」相差多少？

如果兩個不同位置存放相同數值，它們的絕對差就是 `0`，此時低分也是 `0`。

### 2. 高分（high score）

同樣考慮所有元素配對，當中**最大的絕對差**就是高分。

也就是問：陣列中「數值相距最遠的兩個元素」相差多少？

低分與高分各自從所有配對中取值，不要求由同一組元素產生。

### 3. 總分（score）

將低分與高分相加，得到陣列的總分：

```text
總分 = 低分 + 高分
     = 所有元素配對中的最小絕對差 + 所有元素配對中的最大絕對差
```

這裡的低分、高分都不是陣列中的最小元素或最大元素，也不是把所有配對的絕對差加總。

## 四、可以修改什麼？

題目允許修改 `nums` 中兩個位置的元素：

- 替換這兩個位置的數值，其餘位置保留原值。
- 新數值不受限於原陣列已有的數值，可以使用原陣列中沒有出現過的整數。
- 修改後的數值仍是整數；兩個位置可以改成相同的數值。
- 只能替換原有位置的數值，不能增加或刪除陣列位置，因此元素個數維持不變。
- 修改完成後，以整個陣列重新計算低分、高分與總分。

計算分數時，沒有被修改的元素也必須一起納入比較，不能只看被修改的那兩個元素。

## 五、題目究竟要求回傳什麼？

題目要的是：**在允許修改兩個元素的條件下，修改後能達到的最小總分。**

可以把題意分成兩個層次理解：

1. 對某一個修改後的陣列，先依照定義算出它的低分、高分與總分。
2. 題目要求的是所有允許的修改方式中，最小的那個總分。

「低分」和「最小總分」是不同概念：低分只是總分的一部分，題目最終要回傳的答案仍然是 **低分 + 高分** 所能達到的最小值。

回傳值是一個整數，不需要回傳修改後的陣列、修改的位置，或各位置改成的數值。官方範例展示修改後的陣列，是為了協助理解答案的意義。

## 六、輸入限制

| 項目 | 官方限制 | 意義 |
| --- | --- | --- |
| 陣列長度 | `3 <= nums.length <= 10^5` | 至少有 3 個元素，最多有 100,000 個元素。 |
| 元素數值 | `1 <= nums[i] <= 10^9` | 輸入陣列中的每個元素，介於 1 與 1,000,000,000 之間。 |

輸入可能包含重複數值，題目沒有要求所有元素互不相同。

## 七、官方範例說明

以下使用官方提供的兩個範例，說明修改動作與分數的計算。範例中的修改方式用來解釋結果，不延伸討論如何找出最佳修改方式。

### 範例一

**輸入：**

```text
nums = [1,4,7,8,5]
```

**輸出：**

```text
3
```

官方將 `nums[0]` 與 `nums[1]` 都改成 `6`。索引從 `0` 開始，具體修改如下：

- 第一個位置 `nums[0]`：原本的 `1` 改成 `6`。
- 第二個位置 `nums[1]`：原本的 `4` 改成 `6`。
- 其餘三個位置的數值 `7`、`8`、`5` 保持不變。

```text
修改前：[1,4,7,8,5]  → 5 個元素
修改後：[6,6,7,8,5]  → 5 個元素
```

雖然 `6` 沒有出現在原陣列中，仍然可以用作修改後的數值。這兩個 `6` 分別取代原本的 `1` 和 `4`，沒有在陣列末端多加一個元素，所以修改前後都是 **5 個元素**。

接著依照定義計算：

| 分數 | 取值理由 | 計算結果 |
| --- | --- | --- |
| 低分 | 前兩個位置的數值都是 `6`，這組差距為零，已是最小可能的絕對差。 | `\|6 - 6\| = 0` |
| 高分 | 整個陣列中數值相距最遠的是 `8` 與 `5`。 | `\|8 - 5\| = 3` |
| 總分 | 將低分與高分相加。 | `0 + 3 = 3` |

注意：高分使用的 `8` 和 `5` 都不是這次被修改的元素，仍然必須納入計算。它們在陣列中的位置是否相鄰，不會影響配對資格。

官方給出的最小總分是 `3`，所以回傳 `3`；不是回傳低分 `0`，也不是回傳修改後的陣列。

### 範例二

**輸入：**

```text
nums = [1,4,3]
```

**輸出：**

```text
0
```

官方將 `nums[1]` 與 `nums[2]` 都改成 `1`，也就是修改第二個與第三個元素：

```text
修改前：[1,4,3]
修改後：[1,1,1]
```

此時任意兩個不同位置的元素，數值都是 `1`：

| 分數 | 取值理由 | 計算結果 |
| --- | --- | --- |
| 低分 | 所有配對的絕對差都是零，最小值也是零。 | `\|1 - 1\| = 0` |
| 高分 | 所有配對的絕對差都是零，最大值也是零。 | `\|1 - 1\| = 0` |
| 總分 | 將低分與高分相加。 | `0 + 0 = 0` |

因為絕對差不會是負數，總分也不會小於 `0`。這個範例已經達到 `0`，所以回傳 `0`。
