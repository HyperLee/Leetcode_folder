## 題目說明

給定一個 `m × n` 的二元矩陣 `grid`。一次操作可以選擇任意一列或任意一欄，將該列或該欄的每個位元反轉：

- `0` 變成 `1`
- `1` 變成 `0`

矩陣的每一列都視為一個二進位數，矩陣分數是所有列代表之二進位數的總和。可以執行任意次操作，也可以完全不操作；目標是回傳可得到的最高分數。

題目連結：

- [LeetCode 861. Score After Flipping Matrix](https://leetcode.com/problems/score-after-flipping-matrix/)
- [力扣 861. 翻转矩阵后的得分](https://leetcode.cn/problems/score-after-flipping-matrix/)

### 官方範例一

輸入為 `[[0,0,1,1],[1,0,1,0],[1,1,0,0]]`，輸出為 `39`。

經過適當的列與欄翻轉後，可以得到：

- `1111₂ = 15`
- `1001₂ = 9`
- `1111₂ = 15`

因此總分為 `15 + 9 + 15 = 39`。

### 官方範例二

輸入為 `[[0]]`，輸出為 `1`。只要翻轉唯一的一列或唯一的一欄，就能將 `0` 變成 `1`。

## 限制條件

- `m == grid.Length`
- `n == grid[i].Length`
- `1 <= m, n <= 20`
- `grid[i][j]` 只能是 `0` 或 `1`

> [!NOTE]
> `MatrixScore` 依題目契約處理非空、每列等長的二元矩陣，不額外驗證空矩陣、鋸齒狀陣列或非二元數值。

矩陣最多有 20 列、每列最多 20 個位元。最高總分不超過 `20 × (2²⁰ - 1) = 20,971,500`，可安全存入 C# 的 `int`。

## 解題概念與出發點

直接模擬所有列與欄的翻轉組合會產生大量可能性。更重要的觀察是：不同位元對二進位數的貢獻並不相同，而且一旦先決定每列是否翻轉，後續每一欄就可以獨立最佳化。

### 觀察一：每列最高位一定要是 `1`

一個長度為 `n` 的二進位數，最高位權重是 `2^(n - 1)`；其右側所有位元即使全部為 `1`，權重總和也只有：

`2^(n - 2) + ... + 2¹ + 2⁰ = 2^(n - 1) - 1`

因此：

`最高位權重 > 其餘所有位元權重總和`

若某列的第一個位元是 `0`，翻轉整列必定使這一列的數值變大。若第一個位元已是 `1`，則不需要翻列。最佳答案中，每列第一個位元必定都是 `1`。

### 觀察二：不必真的翻轉每一列

對任意位置 `grid[i][j]`：

- 若 `grid[i][0] == 1`，該列不翻轉，位置 `j` 的值仍是 `grid[i][j]`
- 若 `grid[i][0] == 0`，該列必須翻轉，位置 `j` 的值會是 `1 - grid[i][j]`

因此只要根據每列原始最高位，就能推導該列「虛擬翻轉後」的所有位元。程式不需要複製或修改矩陣。

### 觀察三：每個後續欄位可以獨立選擇

完成列的虛擬翻轉後，考慮某個非最高位欄：

- 假設該欄有 `ones` 個 `1`
- 該欄共有 `m` 個值，因此有 `m - ones` 個 `0`
- 不翻欄可以保留 `ones` 個 `1`
- 翻欄可以得到 `m - ones` 個 `1`

為了讓該欄貢獻最大，只要選擇：

`max(ones, m - ones)`

欄與欄之間互不影響，所以可以逐欄做出最佳選擇，再把每欄的最佳貢獻相加。

## 解法：不實際翻轉的貪心計分

主要方法是 `MatrixScore(int[][] grid)`。

### 步驟一：直接計算最高位貢獻

最佳狀態下，每列最高位都是 `1`。共有 `m` 列，每個最高位的權重為 `2^(n - 1)`，所以初始分數是：

`m × 2^(n - 1)`

這一步不需要逐列檢查，因為我們已經證明所有最高位都應視為 `1`。

### 步驟二：統計每個後續欄位的虛擬 `1`

從欄索引 `1` 開始，逐列判斷：

| 原始最高位 | 原始目前位元 | 虛擬翻列後的目前位元 |
| --- | --- | --- |
| `1` | `0` | `0` |
| `1` | `1` | `1` |
| `0` | `0` | `1` |
| `0` | `1` | `0` |

程式分別以 `grid[i][j]` 或 `1 - grid[i][j]` 累加 `nOnes`。

### 步驟三：選擇是否翻轉目前欄

目前欄虛擬翻列後有 `nOnes` 個 `1`：

- 不翻欄：保留 `nOnes` 個 `1`
- 翻欄：得到 `m - nOnes` 個 `1`

令 `k = max(nOnes, m - nOnes)`，此欄位權重為 `2^(n - j - 1)`，欄位貢獻就是：

`k × 2^(n - j - 1)`

將每個欄位貢獻加入總分，最後即為最大分數。

### 為何貪心選擇正確

1. 每列最高位為 `0` 時，翻列得到的最高位增益大於其餘所有位元可能造成的損失，因此最佳答案一定會使每列最高位成為 `1`。
2. 每列是否翻轉因此已由原始最高位唯一決定，後續每個位置的虛擬值也隨之確定。
3. 翻轉某一欄只影響該欄，不會改變其他欄；所以每欄都可獨立選擇保留 `nOnes` 或翻成 `m - nOnes`。
4. 每欄選擇較大的 `1` 數量，再乘上固定權重，會讓該欄貢獻最大。
5. 所有欄位都各自最大時，其貢獻總和就是整個矩陣的最大分數。

### 輸入是否會被修改

不會。`MatrixScore` 只讀取 `grid[i][0]` 與 `grid[i][j]`，利用算式推導翻轉後的值，不對任何陣列元素賦值。

### 複雜度

令 `m` 為列數、`n` 為欄數：

- 時間複雜度：`O(m × n)`，每個非最高位位置最多讀取一次
- 額外空間複雜度：`O(1)`，只使用列數、欄數、計數器與總分
- 結果空間複雜度：`O(1)`，只回傳一個整數

## 範例演示流程

以官方範例 `[[0,0,1,1],[1,0,1,0],[1,1,0,0]]` 說明。

### 1. 判斷每列的虛擬翻轉

| 原始列 | 最高位 | 決策 | 虛擬翻列結果 |
| --- | --- | --- | --- |
| `0011` | `0` | 翻列 | `1100` |
| `1010` | `1` | 不翻列 | `1010` |
| `1100` | `1` | 不翻列 | `1100` |

此時只是在概念上得到 `1100`、`1010`、`1100`，原始矩陣並未改變。

### 2. 計算最高位

共有 `3` 列、每列 `4` 個位元，最高位權重為 `2³ = 8`：

`最高位貢獻 = 3 × 8 = 24`

### 3. 逐欄選擇最佳方向

| 欄索引 | 虛擬翻列後的欄值 | 原有 `1` 數 | 翻欄後 `1` 數 | 採用的 `1` 數 | 權重 | 貢獻 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| `1` | `1, 0, 1` | 2 | 1 | 2 | 4 | 8 |
| `2` | `0, 1, 0` | 1 | 2 | 2 | 2 | 4 |
| `3` | `0, 0, 0` | 0 | 3 | 3 | 1 | 3 |

- 欄 `1` 不翻轉
- 欄 `2` 翻轉
- 欄 `3` 翻轉

### 4. 合計

`24 + 8 + 4 + 3 = 39`

若真的套用上述欄翻轉，三列會成為 `1111`、`1001`、`1111`，分別代表 `15`、`9`、`15`，總和同樣是 `39`。
