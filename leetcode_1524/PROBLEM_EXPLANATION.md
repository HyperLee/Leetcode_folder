# 1524. Number of Sub-arrays With Odd Sum

## 題目想求什麼？

給定一個整數陣列 `arr`，題目要你數出 **有多少個子陣列的元素總和是奇數**。每個子陣列都有自己的起點和終點。把這段區間內的元素全部加起來，總和是奇數就計入 1 個，總和是偶數就計入 0 個。

例如，`[1, 3, 5]` 這個子陣列的總和是 `1 + 3 + 5 = 9`。因為 `9` 是奇數，所以這整段對答案貢獻的是 **1 個**。

**輸出是一個整數**。設符合條件的子陣列共有 `count` 個，題目要求回傳 `count % 1,000,000,007`，也就是個數除以 `10^9 + 7` 的餘數。當個數小於模數時，餘數就是原本的個數。例如 `4 % 1,000,000,007 = 4`。如果個數是 `1,000,000,010`，回傳值就是 `3`。

## 什麼是子陣列？

子陣列是原陣列中一段**連續且非空**的元素。本文用 `[l, r]` 表示從索引 `l` 到索引 `r` 的區間，起點和終點都包含在內，索引從 `0` 開始。

```text
索引       0  1  2
元素       1  3  5
區間 [0,1] └──┘
```

- 區間 `[0, 1]` 包含元素 `[1, 3]`，這兩個元素相鄰。
- 只取元素 `1` 和 `5` 會跳過索引 `1` 的元素 `3`，因此這樣取出的 `[1, 5]` 不符合連續條件。
- 起點和終點可以相同，例如 `[2, 2]` 只包含元素 `[5]`。也可以取整個陣列，例如 `[0, 2]` 包含 `[1, 3, 5]`。

區間由索引決定。以 `arr = [1, 1]` 為例，區間 `[0, 0]` 和 `[1, 1]` 的內容都是 `[1]`，但位於不同位置，各計入 1 個。整段 `[0, 1]` 的總和是 `2`，所以答案是 **2**。

## 官方範例

### 範例一｜`arr = [1, 3, 5]`

| 索引區間 | 子陣列元素 | 元素總和 | 是否計入 |
| --- | --- | ---: | --- |
| `[0, 0]` | `[1]` | 1 | 是 |
| `[0, 1]` | `[1, 3]` | 4 | 否 |
| `[0, 2]` | `[1, 3, 5]` | 9 | 是 |
| `[1, 1]` | `[3]` | 3 | 是 |
| `[1, 2]` | `[3, 5]` | 8 | 否 |
| `[2, 2]` | `[5]` | 5 | 是 |

六個子陣列中，有四個區間的總和是奇數。這四個區間的總和分別是 `1`、`9`、`3`、`5`，所以回傳 **4**。

### 範例二｜`arr = [2, 4, 6]`

這個陣列的每個元素都是偶數，因此任一連續區間內的元素相加都會得到偶數。例如，單一元素 `[2]` 的總和是 `2`，相鄰的 `[4, 6]` 總和是 `10`，整段 `[2, 4, 6]` 的總和是 `12`。符合條件的子陣列有 **0** 個。

### 範例三｜`arr = [1, 2, 3, 4, 5, 6, 7]`

例如，區間 `[1, 3]` 包含 `[2, 3, 4]`，總和是 `2 + 3 + 4 = 9`，所以這個區間計入 1 個。下表把所有符合條件的區間依起點整理，括號內是該區間的元素總和。

| 起點索引 | 總和為奇數的區間（總和） | 個數 |
| ---: | --- | ---: |
| 0 | `[0, 0]`（1）、`[0, 1]`（3）、`[0, 4]`（15）、`[0, 5]`（21） | 4 |
| 1 | `[1, 2]`（5）、`[1, 3]`（9）、`[1, 6]`（27） | 3 |
| 2 | `[2, 2]`（3）、`[2, 3]`（7）、`[2, 6]`（25） | 3 |
| 3 | `[3, 4]`（9）、`[3, 5]`（15） | 2 |
| 4 | `[4, 4]`（5）、`[4, 5]`（11） | 2 |
| 5 | `[5, 6]`（13） | 1 |
| 6 | `[6, 6]`（7） | 1 |

各起點的小計加起來是 `4 + 3 + 3 + 2 + 2 + 1 + 1 = 16`，所以回傳 **16**。

## 輸入限制

- `1 ≤ arr.length ≤ 100,000`，陣列至少包含一個元素。
- `1 ≤ arr[i] ≤ 100`，每個元素都是介於 `1` 和 `100` 之間的整數，包含兩端。
