## 題目說明

給定一個非負整數 `n`，回傳長度為 `n + 1` 的整數陣列 `ans`。對每個
`0 <= i <= n`，`ans[i]` 必須等於 `i` 的二進位表示中數字 `1` 的個數。

題目連結：

- [LeetCode 338 - Counting Bits](https://leetcode.com/problems/counting-bits/description/)
- [力扣 338 - 位元數](https://leetcode.cn/problems/counting-bits/description/)

### 官方範例

```text
輸入：n = 2
輸出：[0, 1, 1]
說明：
0 的二進位表示為 0，共有 0 個 1。
1 的二進位表示為 1，共有 1 個 1。
2 的二進位表示為 10，共有 1 個 1。

輸入：n = 5
輸出：[0, 1, 1, 2, 1, 2]
說明：0 到 5 的二進位表示依序為 0、1、10、11、100、101。
```

## 限制條件

- `0 <= n <= 100000`
- 回傳陣列必須包含 `0` 到 `n`，因此長度固定為 `n + 1`。
- `ans[0]` 必定為 `0`，因為 `0` 的二進位表示不含任何 `1`。
- 兩種實作都假設輸入符合題目限制，不另外定義負數輸入的行為。

## 解題概念與出發點

最直接的方式是逐一檢查 `0` 到 `n`，再對每個數字獨立計算位元 `1` 的數量。
若每個數字都逐位掃描，單一數字最多需要 `O(log n)` 次操作，總時間會是
`O(n log n)`。

這題的關鍵是：較大數字的位元計數可以由已經算好的較小數字推導，不必重新掃描
整個二進位表示。由 `1` 遞增到 `n` 時，只要用常數時間完成一次遞推，總時間便能
降為 `O(n)`。

兩種解法都建立長度為 `n + 1` 的結果陣列：

```text
索引：  0  1  2  3  4  5
二進位：0  1 10 11 100 101
結果：  0  1  1  2  1   2
```

結果陣列本身是題目要求的輸出，所以一定需要 `O(n)` 空間；若不計回傳陣列，
兩種解法都只使用固定數量的區域變數，額外空間為 `O(1)`。

## 解法一：右移與最低位

### 設計說明

`CountBits` 使用以下遞推式：

```text
dp[i] = dp[i >> 1] + (i & 1)
```

這個式子把目前數字拆成兩部分：

1. `i >> 1` 將 `i` 右移一位，也就是移除最低位。結果一定小於 `i`，因此
   `dp[i >> 1]` 在由小到大的迴圈中已經算好。
2. `i & 1` 只檢查最低位。最低位為 `1` 時結果是 `1`，為 `0` 時結果是 `0`。
3. 將「移除最低位後的 1 數量」與「最低位是否為 1」相加，即為 `i` 的答案。

以二進位 `1011` 為例：

```text
i        = 1011
i >> 1   = 0101，已知其中有 2 個 1
i & 1    = 1
dp[i]    = 2 + 1 = 3
```

### 正確性說明

任一非負整數 `i` 都能唯一拆成「移除最低位後的高位部分」及「最低位」。
`i >> 1` 保留高位部分的所有 `1`，`i & 1` 則精確表示最低位是否額外貢獻一個
`1`。兩者涵蓋 `i` 的所有位元且沒有重複，因此遞推結果正確。

### 範例演示：`n = 5`

`dp[0]` 由陣列初始值設為 `0`，接著依序計算：

| `i` | 二進位 | `i >> 1` | `dp[i >> 1]` | `i & 1` | `dp[i]` |
| ---: | ---: | ---: | ---: | ---: | ---: |
| `1` | `1` | `0` | `0` | `1` | `1` |
| `2` | `10` | `1` | `1` | `0` | `1` |
| `3` | `11` | `1` | `1` | `1` | `2` |
| `4` | `100` | `2` | `1` | `0` | `1` |
| `5` | `101` | `2` | `1` | `1` | `2` |

最後得到 `[0, 1, 1, 2, 1, 2]`。

### 複雜度

- 時間複雜度：`O(n)`，每個索引只進行一次常數時間遞推。
- 回傳陣列空間：`O(n)`。
- 不計回傳陣列的額外空間：`O(1)`。

## 解法二：奇偶遞推

### 設計說明

`CountBits2` 直接利用整數的奇偶性：

```text
i 為偶數：result[i] = result[i / 2]
i 為奇數：result[i] = result[i - 1] + 1
```

偶數的二進位最低位必定是 `0`。除以 `2` 等同右移一位，只會移除這個 `0`，
所以位元 `1` 的數量不變。

奇數的二進位最低位必定是 `1`。`i - 1` 會將最低位從 `1` 改為 `0`，且不影響
其他位元，因此奇數恰好比前一個偶數多一個位元 `1`。

### 正確性說明

每個正整數不是偶數就是奇數：

- 若 `i` 為偶數，可寫成 `2k`。其二進位是 `k` 的二進位向左移一位並補 `0`，
  因此 `result[i] = result[k] = result[i / 2]`。
- 若 `i` 為奇數，可寫成 `2k + 1`。`i - 1 = 2k` 與 `i` 只有最低位不同，
  因此 `result[i] = result[i - 1] + 1`。

兩個分支涵蓋所有正整數，且都只依賴較小索引的已知結果，所以由 `result[0] = 0`
開始即可正確算出整個陣列。

### 範例演示：`n = 5`

| `i` | 二進位 | 奇偶 | 使用的已知結果 | 計算 | `result[i]` |
| ---: | ---: | --- | --- | --- | ---: |
| `1` | `1` | 奇數 | `result[0] = 0` | `0 + 1` | `1` |
| `2` | `10` | 偶數 | `result[1] = 1` | `result[2 / 2]` | `1` |
| `3` | `11` | 奇數 | `result[2] = 1` | `1 + 1` | `2` |
| `4` | `100` | 偶數 | `result[2] = 1` | `result[4 / 2]` | `1` |
| `5` | `101` | 奇數 | `result[4] = 1` | `1 + 1` | `2` |

最後同樣得到 `[0, 1, 1, 2, 1, 2]`。

### 複雜度

- 時間複雜度：`O(n)`，每個索引只進行一次奇偶判斷與遞推。
- 回傳陣列空間：`O(n)`。
- 不計回傳陣列的額外空間：`O(1)`。

## 兩種解法比較

| 比較項目 | 解法一：右移＋最低位 | 解法二：奇偶遞推 |
| --- | --- | --- |
| 公開 API | `CountBits(int n)` | `CountBits2(int n)` |
| 遞推式 | `dp[i >> 1] + (i & 1)` | 偶數取 `result[i / 2]`；奇數取 `result[i - 1] + 1` |
| 核心觀察 | 拆開高位部分與最低位 | 分別描述偶數與奇數的最低位 |
| 分支 | 無 | 需要判斷奇偶 |
| 時間複雜度 | `O(n)` | `O(n)` |
| 回傳陣列空間 | `O(n)` | `O(n)` |
| 額外空間 | `O(1)` | `O(1)` |
| 教學重點 | 位移與位元遮罩 | 二進位的奇偶性質 |
