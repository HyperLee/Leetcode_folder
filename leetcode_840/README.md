# LeetCode 840：矩陣中的幻方

這是一個使用 C# 與 .NET 10 撰寫的主控台教學專案，示範如何在整數網格中尋找所有 `3 x 3` 正常幻方。專案保留完整驗證法，並加入利用洛書旋轉與鏡射結構的外圈序列法，方便比較一般定義檢查與結構辨識兩種思考方式。

> 題目連結：[840. Magic Squares In Grid](https://leetcode.com/problems/magic-squares-in-grid/description/)

## 題目說明

`3 x 3` 幻方由 `1` 到 `9` 九個互不重複的整數組成，且三列、三行與兩條對角線的總和都相同。

給定一個 `row x col` 的整數網格 `grid`，請計算其中有多少個連續的 `3 x 3` 子矩陣是幻方。原始網格可以包含 `0` 到 `15`，但真正的幻方仍只能使用 `1` 到 `9`。

官方範例：

```text
grid = [[4, 3, 8, 4], [9, 5, 1, 9], [2, 7, 6, 2]]
```

左側的 `3 x 3` 子矩陣是幻方：

```text
4 3 8
9 5 1
2 7 6
```

右側子矩陣的中心是 `1`，不符合正常幻方中心必為 `5` 的條件，因此答案為 `1`。

## 限制條件與輸入前提

- `row == grid.Length`
- `col == grid[i].Length`
- `1 <= row, col <= 10`
- `0 <= grid[i][j] <= 15`
- 輸入為非空矩形網格，每一列具有相同長度。
- 公開方法依照題目限制設計，不額外處理 `null`、空網格或不規則陣列。
- 當列數或欄數小於 `3` 時，不存在候選子矩陣，結果自然為 `0`。

## 解題概念與出發點

### 為什麼每條線的總和是 15

正常幻方恰好使用 `1` 到 `9`：

```text
1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 + 9 = 45
```

三列的總和相同，且三列涵蓋全部九格，因此每列必須是：

```text
45 / 3 = 15
```

相同定義也要求三行與兩條對角線的總和為 `15`。

### 為什麼中心一定是 5

考慮穿過中心的四條線：中間列、中間行與兩條對角線。四條線的總和為 `4 x 15 = 60`。

- 八個外圈數字各被計算一次。
- 中心數字被四條線各計算一次，共出現四次。
- 九個數字的總和為 `45`。

若中心為 `center`，外圈總和就是 `45 - center`：

```text
60 = (45 - center) + 4 x center
60 = 45 + 3 x center
center = 5
```

所以中心值不是 `5` 時，可以立刻排除候選區域。

### 為什麼只有八種配置

`3 x 3` 正常幻方的基本形式稱為洛書。固定其中一種配置後，將它旋轉 `0°`、`90°`、`180°`、`270°` 可得到四種配置；再對每種配置做鏡射，共得到八種。

本專案使用兩種方法：

| 方法 | 核心概念 | 每個候選的判定方式 | 總時間複雜度 | 額外空間 |
| --- | --- | --- | --- | --- |
| `NumMagicSquaresInside` | 依照幻方定義完整驗證 | 唯一性、三列、三行、兩對角線 | `O(row x col)` | `O(1)` |
| `NumMagicSquaresInside2` | 辨識洛書結構 | 中心 `5` 與外圈循環模式 | `O(row x col)` | `O(1)` |

兩種方法都只掃描所有可能的中心位置。每個候選固定檢查九格，所以單次判定雖然包含多個步驟，仍為常數時間。

## 解法一：完整驗證法

### 設計說明

`NumMagicSquaresInside` 只枚舉不位於網格邊界的座標。若中心為 `(row, column)`，對應的候選範圍就是：

```text
row - 1 到 row + 1
column - 1 到 column + 1
```

每個候選交給 `IsMagicSquare` 依序檢查：

1. **中心是否為 5**：這是成本最低的必要條件，可以快速排除大部分候選。
2. **九格是否恰好使用 1 到 9**：使用最多只保存九個元素的 `HashSet<int>`。數字超出範圍或重複時立即失敗。
3. **三列與三行是否都等於 15**：每個偏移量同時計算一列與一行，任一總和錯誤就停止。
4. **兩條對角線是否都等於 15**：前述條件全部成立後，再完成最後兩條線的驗證。

### 為什麼判定正確

- 若方法回傳 `true`，九格已證明是互不重複的 `1` 到 `9`，而三列、三行與兩條對角線都等於 `15`，完全符合題目定義。
- 若候選是合法幻方，它必定以 `5` 為中心、使用 `1` 到 `9` 各一次，且所有指定線段總和為 `15`，所以不會被任何檢查錯誤排除。

因此完整驗證法既不會接受非法候選，也不會漏掉合法幻方。

### 複雜度

假設網格尺寸為 `row x col`：

- 候選中心最多有 `(row - 2) x (col - 2)` 個。
- 每個候選固定檢查九個位置與八條線，皆為常數操作。
- 時間複雜度：`O(row x col)`
- 額外空間複雜度：`O(1)`，因為集合最多只保存九個數字。

### 範例演示流程

使用官方案例：

```text
[[4, 3, 8, 4],
 [9, 5, 1, 9],
 [2, 7, 6, 2]]
```

網格只有一列可能成為中心，欄索引分別為 `1` 與 `2`：

| 中心 | 中心值 | 數字唯一性 | 行列與對角線 | 結果 |
| --- | ---: | --- | --- | --- |
| `(1, 1)` | 5 | `1` 到 `9` 各一次 | 全部為 15 | 合法，累計變成 1 |
| `(1, 2)` | 1 | 不需繼續 | 不需繼續 | 中心不是 5，排除 |

掃描結束後得到 `1`。

## 解法二：中心值與外圈循環序列

### 設計說明

所有正常 `3 x 3` 幻方都是洛書的旋轉或鏡射。以標準洛書為例：

```text
4 3 8
9 5 1
2 7 6
```

從左上角開始，依「左上、上、右上、右、右下、下、左下、左」順時針讀取外圈：

```text
4 -> 3 -> 8 -> 1 -> 6 -> 7 -> 2 -> 9
```

得到基準序列 `43816729`。把序列重複一次：

```text
4381672943816729
```

任何旋轉只會改變讀取起點，因此都會是這個重複字串中的連續八位子字串。

鏡射會反轉外圈方向。基準序列的反向循環為：

```text
92761834
```

同樣重複一次得到：

```text
9276183492761834
```

`IsMagicSquareByOuterRing` 的流程如下：

1. 中心不是 `5` 時立即排除。
2. 順時針取得八個外圈值並串成文字。
3. 檢查外圈是否出現在正向或反向重複模式中。
4. 任一模式命中就代表候選是八種洛書配置之一。

這個比對也隱含保證外圈恰好使用 `1、2、3、4、6、7、8、9` 各一次。`0`、`10` 到 `15`、重複值或錯誤排列都無法命中模式。

### 為什麼判定正確

- 正常 `3 x 3` 幻方只有八種洛書配置，分別是四種旋轉與四種鏡射。
- 旋轉只改變外圈序列的起點，因此由正向重複模式涵蓋。
- 鏡射會改變繞行方向，因此由反向重複模式涵蓋。
- 中心另外要求為 `5`，外圈模式則精確包含其餘八個合法數字。

所以方法命中模式時一定是合法幻方；合法幻方也一定會命中正向或反向模式。

### 複雜度

- 每個候選只讀取中心與八個外圈位置，並比對固定長度字串。
- 時間複雜度：`O(row x col)`
- 額外空間複雜度：`O(1)`；每個候選建立的外圈文字長度受固定九格限制，不隨輸入網格變大。

相較完整驗證法，這種方法的常數操作較少，也能展示洛書的結構特性；代價是判定依賴本題限定的正常 `3 x 3` 幻方，不適合直接推廣到任意尺寸的幻方。

### 範例演示流程

使用鏡射洛書：

```text
8 3 4
1 5 9
6 7 2
```

1. 中心是 `5`，通過第一個必要條件。
2. 從左上開始順時針讀取外圈，得到 `83492761`。
3. `83492761` 不屬於正向旋轉序列。
4. 它是反向重複模式 `9276183492761834` 的連續八位子字串。
5. 因此判定為合法的鏡射洛書，回傳 `true`。

## 邊界情況

- **列或欄小於 3**：中心掃描迴圈不會執行，結果為 `0`。
- **中心不是 5**：兩種方法都會立即排除。
- **數字重複**：完整驗證法由集合偵測；外圈序列法無法命中合法模式。
- **包含 0 或 10 到 15**：完整驗證法由範圍檢查排除；外圈序列法同樣不會命中。
- **多個幻方重疊或並列**：每個中心獨立判斷，所有合法子矩陣都會被計入。
- **輸入不會被修改**：兩種方法都只讀取網格，因此可安全地用同一案例依序比較。

## 可執行範例

`Main` 會執行七組固定案例，涵蓋官方範例、尺寸不足、標準與鏡射洛書、重複值、超出幻方範圍的值，以及同一網格中的多個幻方。每組案例會以人工推導的預期值分別檢查兩種解法，共有十四項驗證。
