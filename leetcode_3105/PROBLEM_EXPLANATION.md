# 3105. 最長的嚴格遞增或嚴格遞減連續子陣列

給定一個整數陣列 `nums`，從中取出一段連續的元素。這一段可以一路嚴格變大，也可以一路嚴格變小。題目要回傳符合其中一種條件的最長一段有幾個元素。即使有好幾段並列最長，也只需要回傳一個長度。

## 「連續」和「嚴格」是什麼意思？

- **連續子陣列**是原陣列中一段緊鄰的元素。從起點到終點，中間的元素都要保留，順序也要跟原陣列一樣。例如在 `[1, 4, 3]` 裡，`[1, 4]` 和 `[4, 3]` 都是連續的。`[1, 3]` 跳過了中間的 `4`，因此不算。
- **嚴格遞增**表示每個數都比前一個大，例如 `[1, 3, 5]` 滿足 `1 < 3 < 5`。
- **嚴格遞減**表示每個數都比前一個小，例如 `[5, 3, 1]` 滿足 `5 > 3 > 1`。
- **相等會中斷**。例如 `[1, 3, 3]` 中的兩個 `3` 相等，所以整段不符合嚴格遞增。相等也不符合嚴格遞減。
- **只取一個元素也可以**。例如 `[3]` 裡沒有相鄰的兩個元素要比較，所以它同時符合嚴格遞增和嚴格遞減，長度是 `1`。

## 範例一　有轉折，也有相等的數字

輸入為 `nums = [1, 4, 3, 3, 2]`，輸出為 `2`。

原陣列中，第一個 `3` 在第 3 個位置，第二個 `3` 在第 4 個位置。比較相鄰的數字，可以看到 `1 < 4 > 3 = 3 > 2`。

| 在原陣列中的位置（從 1 開始） | 連續子陣列 | 是否符合 |
| --- | --- | --- |
| 第 1 到第 2 個 | `[1, 4]` | 嚴格遞增，因為 `1 < 4` |
| 第 2 到第 3 個 | `[4, 3]` | 嚴格遞減，因為 `4 > 3` |
| 第 3 到第 4 個 | `[3, 3]` | 兩個數相等，兩種條件都不符合 |
| 第 4 到第 5 個 | `[3, 2]` | 嚴格遞減，因為第二個 `3` 後面緊接著 `2` |

為什麼沒有長度為 `3` 的合法子陣列？

- `[1, 4, 3]` 先變大再變小。
- `[4, 3, 3]` 和 `[3, 3, 2]` 都包含兩個相等的 `3`。
- `[4, 3, 2]` 的數值確實嚴格遞減，但要從原陣列取出這三個數，必須跳過其中一個 `3`，所以它不算連續子陣列。

更長的一段也一定會包含上面某段不符合條件的連續三個元素。因此最長的合法子陣列有 `2` 個元素。

## 範例二　每個數字都相同

輸入為 `nums = [3, 3, 3, 3]`，輸出為 `1`。

單獨取第 1、2、3 或 4 個位置的元素，都會得到 `[3]`。這四段的值相同，但取自不同位置，所以官方說明會列出四次 `[3]`。

只要取兩個以上連續的元素，就會遇到 `3 = 3`。因此每段合法子陣列都只有一個元素，最長長度是 `1`。

## 範例三　整個陣列一路變小

輸入為 `nums = [3, 2, 1]`，輸出為 `3`。

- 只取一個元素時，`[3]`、`[2]` 和 `[1]` 同時符合兩種條件。
- 取兩個連續元素時，`[3, 2]` 和 `[2, 1]` 都是嚴格遞減。
- 取整段 `[3, 2, 1]` 時，相鄰數字滿足 `3 > 2 > 1`，所以整段也是嚴格遞減。

整個陣列已經符合條件，這一段共有 `3` 個元素，因此回傳 `3`。
