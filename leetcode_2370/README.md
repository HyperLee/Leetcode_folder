## 題目說明

[2370. Longest Ideal Subsequence](https://leetcode.com/problems/longest-ideal-subsequence/solutions/) 要求在給定的小寫英文字串 `s` 中，找出最長的「理想子序列」，並回傳其長度。

一個字串 `t` 必須同時符合以下條件，才是理想字串：

1. `t` 是 `s` 的子序列；也就是可以從 `s` 刪除零個或多個字元形成 `t`，但不能改變剩餘字元的相對順序。
2. `t` 中任意兩個相鄰字母的字母序距離絕對值都不超過 `k`。

字母序不會循環。例如 `'a'` 與 `'z'` 的距離是 `25`，不是 `1`。

## 限制條件

- `1 <= s.Length <= 100,000`
- `0 <= k <= 25`
- `s` 只包含小寫英文字母 `'a'` 到 `'z'`
- 輸出為最長理想子序列的長度

## 解題概念與出發點

直接列舉所有子序列不可行：長度為 `n` 的字串可能有多達 `2^n` 個子序列，而 `n` 最大可達 100,000。

真正影響「目前字母能不能接到既有子序列後面」的資訊，只有該子序列最後一個字母。過去選了哪些索引並不重要；只要知道：

> 目前已處理的字元中，以每一個字母結尾的最長理想子序列分別有多長？

英文小寫字母只有 26 個，因此可以把龐大的子序列搜尋空間壓縮成固定大小的 `dp[26]`。

## 解法：以結尾字母為狀態的動態規劃

### 狀態定義

`dp[c]` 表示在目前已掃描的字串前綴中，以字母索引 `c` 結尾的最長理想子序列長度。

- `c = 0` 代表 `'a'`
- `c = 1` 代表 `'b'`
- ...
- `c = 25` 代表 `'z'`

初始時尚未處理任何字元，因此所有狀態都是 `0`。

### 狀態轉移

依原字串由左到右處理字元，才能自然維持子序列的相對順序。假設目前字母索引為 `c`，合法的前一個結尾字母索引 `p` 必須符合：

```text
|c - p| <= k
```

從所有合法的 `dp[p]` 中取最大值，再接上目前字母：

```text
dp[c] = 1 + max(dp[p])，其中 |c - p| <= k
```

若先前沒有任何可接續的字母，最大值為 `0`，目前字母本身便形成長度為 `1` 的子序列。

### 為什麼可以直接更新同一個陣列？

每個輸入字元只處理一次。處理目前字元時，`dp` 保存的是所有已處理位置能形成的最佳結果；更新 `dp[c]` 代表新增一個以目前位置結尾的候選答案。

因為 `k >= 0`，字母 `c` 自己一定在合法範圍內，所以轉移時也會讀到更新前的 `dp[c]`。重複字母因此能在原有結果上延長，而且狀態值不會變小。

### 演算法步驟

1. 建立長度為 26 的整數陣列 `dp`，全部初始化為 `0`。
2. 由左到右讀取 `s` 的每個字元，轉換成 `0` 到 `25` 的字母索引。
3. 檢查 26 個可能的前一字母狀態，只保留與目前字母距離不超過 `k` 的狀態。
4. 取合法狀態的最大長度，加一後寫回目前字母的狀態。
5. 同步維護所有狀態中的最大長度，掃描完成後回傳該值。

### 正確性說明

處理任一目前字母 `c` 時，任何以它結尾的理想子序列，在移除最後的 `c` 後，只可能是空序列，或是一個以字母 `p` 結尾且滿足 `|c - p| <= k` 的理想子序列。

`dp[p]` 已經保存每一種合法結尾 `p` 的最佳長度，因此從這些狀態取最大值再加一，會得到以目前 `c` 結尾的最佳解。由於字元按原索引順序處理，所有轉移都符合子序列的順序要求。最後取所有結尾字母狀態的最大值，即為整個字串的最長理想子序列長度。

### 複雜度分析

- 時間複雜度：`O(26n) = O(n)`。每個字元固定檢查 26 個字母狀態。
- 空間複雜度：`O(26) = O(1)`。狀態陣列大小不隨輸入長度增加。

## 範例演示流程

以官方範例 `s = "acfgbd"`、`k = 2` 為例。下表只列出每一步實際改動的狀態；「最佳合法前態」是更新前合法範圍中的最大值。

| 步驟 | 目前字母 | 合法前一字母範圍 | 最佳合法前態 | 更新後狀態 | 代表性子序列 | 全域最大值 |
| ---: | :---: | :---: | ---: | :---: | :---: | ---: |
| 1 | `a` | `a`～`c` | 0 | `dp[a] = 1` | `a` | 1 |
| 2 | `c` | `a`～`e` | `dp[a] = 1` | `dp[c] = 2` | `ac` | 2 |
| 3 | `f` | `d`～`h` | 0 | `dp[f] = 1` | `f` | 2 |
| 4 | `g` | `e`～`i` | `dp[f] = 1` | `dp[g] = 2` | `fg` | 2 |
| 5 | `b` | `a`～`d` | `dp[c] = 2` | `dp[b] = 3` | `acb` | 3 |
| 6 | `d` | `b`～`f` | `dp[b] = 3` | `dp[d] = 4` | `acbd` | 4 |

最後得到理想子序列 `"acbd"`。相鄰距離分別是 `2`、`1`、`2`，全部不超過 `k = 2`，所以答案為 `4`。
