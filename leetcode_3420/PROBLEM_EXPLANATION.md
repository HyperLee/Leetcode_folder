# LeetCode 3420｜統計 K 次操作以內得到非遞減子陣列的數目

給定一個整數陣列 `nums` 和一個整數 `k`。從 `nums` 選出一段連續的元素，看看能否在最多 `k` 次「把一個元素加 1」的操作內，讓這一段從左到右維持相等或上升。每個符合條件的區間計入答案一次。

## 什麼是子陣列？

子陣列是原陣列中一段**連續且非空**的元素。用 `[left, right]` 表示區間，索引從 0 開始，包含兩端及中間所有位置。

以 `nums = [3, 1, 1]` 為例，區間 `[0, 1]` 的內容是 `[3, 1]`。取索引 0 和 2 卻跳過索引 1，就不符合連續的條件。單一元素也是子陣列，例如區間 `[1, 1]` 和 `[2, 2]` 的內容都是 `[1]`，但起點與終點不同，所以各算一段。

## 什麼是非遞減？一次操作能做什麼？

非遞減表示每一對相鄰元素都滿足「左邊小於或等於右邊」。例如 `[1, 1, 3]` 符合，因為 `1 ≤ 1 ≤ 3`。`[1, 3, 2]` 則在最後一對出現 `3 > 2`。

- 一次操作只把所選區間中的**一個元素加 1**。同一位置可以操作多次，例如從 `1` 加到 `3` 需要兩次。元素的順序固定，也不能把值減小。
- 每個子陣列都從 `nums` 的原始值開始，並且各自有 `k` 次操作可用。即使兩段包含同一個位置，前一段的調整也不會帶到下一段。
- `k` 是整段可用的操作上限。原本就非遞減的區間用 0 次即可，剛好用完 `k` 次也符合條件。

## 輸入與輸出

| 項目 | 說明 |
| --- | --- |
| `nums` | 原始整數陣列，長度介於 `1` 與 `10^5`，每個元素介於 `1` 與 `10^9` |
| `k` | 每段子陣列最多可用的操作次數，介於 `1` 與 `10^9` |
| 回傳值 | 能在各自的操作上限內變成非遞減的子陣列總數 |

同一個區間只計一次，即使它可以透過不同操作變成多種非遞減的結果。

## 入門範例｜同一個陣列，兩種操作上限

`nums = [3, 1, 1]` 共有六個子陣列。

| 索引區間 | 原始內容 | 變成非遞減至少需要的操作次數 | `k = 2` 時計入 | `k = 4` 時計入 |
| --- | --- | ---: | :---: | :---: |
| `[0, 0]` | `[3]` | 0 | 是 | 是 |
| `[0, 1]` | `[3, 1]` | 2 | 是 | 是 |
| `[0, 2]` | `[3, 1, 1]` | 4 | 否 | 是 |
| `[1, 1]` | `[1]` | 0 | 是 | 是 |
| `[1, 2]` | `[1, 1]` | 0 | 是 | 是 |
| `[2, 2]` | `[1]` | 0 | 是 | 是 |

區間 `[0, 1]` 可以依序變成 `[3, 1] → [3, 2] → [3, 3]`，剛好用兩次操作。接著看區間 `[0, 2]` 時，它仍從 `[3, 1, 1]` 開始。開頭的 `3` 無法減小，後面的兩個 `1` 都至少要變成 `3`，總共需要 `2 + 2 = 4` 次。於是 `k = 2` 時答案是 **5**，`k = 4` 時答案是 **6**。

## 官方範例一｜從 21 段中扣除超出上限的 4 段

`nums = [6, 3, 1, 2, 4, 4]`，`k = 7`。長度從 1 到 6 的子陣列分別有 6、5、4、3、2、1 段，共 21 段。

下表四段都以 `6` 開頭。為了讓數字從左到右不下降，後面的值都至少要達到 `6`。保留開頭的 `6` 並把其餘元素各自加到 `6`，就能達到表中的最低操作次數。

| 索引區間 | 原始內容 | 至少需要的操作次數 |
| --- | --- | ---: |
| `[0, 2]` | `[6, 3, 1]` | `3 + 5 = 8` |
| `[0, 3]` | `[6, 3, 1, 2]` | `3 + 5 + 4 = 12` |
| `[0, 4]` | `[6, 3, 1, 2, 4]` | `3 + 5 + 4 + 2 = 14` |
| `[0, 5]` | `[6, 3, 1, 2, 4, 4]` | `3 + 5 + 4 + 2 + 2 = 16` |

其餘區間都能在 7 次內完成。例如 `[6, 3]` 用 3 次可變成 `[6, 6]`，而 `[3, 1, 2, 4, 4]` 用 3 次可變成 `[3, 3, 3, 4, 4]`。答案是 **21 − 4 = 17**。

## 官方範例二｜按子陣列長度計數

`nums = [6, 3, 1, 3, 6]`，`k = 4`。

| 長度 | 可在 4 次操作內變成非遞減的子陣列 | 段數 |
| ---: | --- | ---: |
| 1 | 五個單一元素區間 | 5 |
| 2 | `[6, 3]`、`[3, 1]`、`[1, 3]`、`[3, 6]` | 4 |
| 3 | `[3, 1, 3]`、`[1, 3, 6]` | 2 |
| 4 | `[3, 1, 3, 6]` | 1 |
| 5 | 無 | 0 |

例如 `[3, 1, 3, 6]` 只要把 `1` 加兩次，就會得到 `[3, 3, 3, 6]`。三個未計入的區間都以 `[6, 3, 1]` 開頭，光是把其中的 `3` 和 `1` 加到 `6` 就需要 8 次。答案是 **5 + 4 + 2 + 1 = 12**。
